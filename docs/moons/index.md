# 위성

착륙할 수 있는 위성 11곳과 회사(71-고르디온)입니다.
위성마다 나오는 몬스터, 폐기물, 몬스터 총량(파워), 날씨 후보가 다릅니다.

!!! info "값의 출처"
    숫자는 게임 에셋(`SelectableLevel`, `EnemyType`)을 직접 읽은 값입니다.
    스폰 규칙은 [몬스터 스폰](spawning.md)에 있습니다.
    시간에 따라 몇 마리쯤 나오는지는 [시간대별 기대 스폰](forecast.md) 그래프를 보세요.

**폐기물**

- 최댓값은 에셋 값 − 1입니다(`Next(minScrap, maxScrap)`).
- 광산 던전이면 6개 더 나옵니다.
- **다인**은 200~249개로 적혀 있지만 실제로는 훨씬 적습니다.
    - 나오는 폐기물이 거의 다 몸 조각(손·발·뼈 등)입니다.
    - 폐기물마다 놓일 수 있는 자리가 정해져 있어서, 맞는 자리가 없으면 건너뜁니다.

**던전(주)**: 가장 자주 나오는 던전입니다. 던전별 확률은 위성 문서에 있습니다.

**날씨**: 그날 날씨가 붙는다면 이 중에서 고른다는 뜻입니다.
날씨가 붙는 위성 수는 [기상](../weather/index.md#날씨가-정해지는-방식)에 있습니다.

게임 데이터에는 `44 Liquidation`과 시험용 레벨도 있지만, 터미널에서 갈 수 없어 뺐습니다.

## 시간

| 항목 | 값 |
|---|---|
| 하루 | 06:00~24:00 |
| 게임 시간 | 1080초 (60초 × 18시간) |
| 시간 배속 | 1.4 |
| 함선 자동 이륙 | 약 23:56 |

- 하루를 0~1로 나타낸 값이 `normalizedTimeOfDay`입니다. (0 = 06:00, 1 = 24:00)
- 몬스터 시간 곡선은 모두 이 값으로 평가합니다.
- 위성 문서의 "06시·08시…" 열이 그 시각의 값입니다.
