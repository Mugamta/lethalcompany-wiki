# 몬스터 스폰

몬스터 스폰은 전부 **호스트**의 `RoundManager`가 합니다.
클라이언트는 결과(생긴 몬스터, 벤트 배정)만 받습니다.

위성·날씨·마감일별로 하루 동안 몇 마리쯤 나오는지는 [시간대별 기대 스폰](forecast.md) 그래프에 있습니다.

## 네 종류의 스폰

| 분류 | 몬스터 목록 | 파워 최대 |
|---|---|---|
| 실내 | `Enemies` | 실내 최대 파워 |
| 외부(야간) | `OutsideEnemies` | 외부 최대 파워 |
| 외부(주간) | `DaytimeEnemies` | 주간 최대 파워 |
| 은폐 수풀 | `WeedEnemies` | 4 (고정) |

**나오는 위치**

- **실내**: 먼저 벤트에 배정되고, 정해진 시각에 벤트에서 나옵니다.
- **외부(야간·주간)**: 바깥 AI 노드에 바로 생깁니다.
- **은폐 수풀**: [은폐 수풀](../environment/vain-shroud.md)을 보세요.

### 파워

- **최대 파워**는 시드로 정해지므로 모든 클라이언트가 같은 값을 압니다.
- **현재 파워**는 스폰할 때만 올라가서, 정확한 값은 호스트만 압니다.
    - 클라이언트는 살아 있는 몬스터의 파워 합으로 추정할 수 있습니다.
- 몬스터가 죽으면 그만큼 파워가 빠집니다(`SubtractFromPowerLevel`).
    - 즉 **죽이면 그만큼 더 나올 수 있습니다.**

## 스폰 배치 시각

호스트의 `RoundManager.Update` 흐름입니다.

1. **85초**(게임 시간)가 지나면 첫 실내 배치를 계획합니다(`BeginEnemySpawning`).
2. 그 뒤 다음 두 조건이 **모두** 맞을 때 새 배치가 돕니다.
    - 시계가 다음 시각(`currentHour`)을 넘음
    - 이번 배치에 벤트로 배정된 몬스터가 **모두 나옴**
3. 새 배치에서는 `currentHour`를 2 올리고 다음 순서로 실행합니다.
    1. 외부 스폰
    2. 은폐 수풀 스폰
    3. 실내 배치 계획

!!! warning "벤트가 없으면 외부도 안 나옴"
    벤트가 하나도 없거나 실내 최대 파워가 0 이하면 1단계가 끝까지 안 돕니다.
    그러면 **외부 스폰도 영영 없습니다.** 회사 위성이 이 경우입니다.

!!! note "배치는 생각보다 늦게 옵니다"
    배치 시각 = max(시계 조건, 앞 배치의 마지막 벤트 시각)

    벤트 몬스터가 늦게 나오도록 배정되면 다음 배치 전체가 밀립니다.

- 스폰 곡선은 **올라간 `currentHour`** 로 평가합니다. 시각이 밀려도 종류·마릿수 계산은 같습니다.
- **시각 조건은 따로 없습니다.** "야간 몬스터"도 곡선 값만 넘으면 낮에 나옵니다.
- 실내 몬스터를 하나도 안 죽이면, 파워가 가득 찬 뒤로는 배치가 시계대로 정확히 옵니다.

## 한 번에 나오는 마릿수

=== "실내"

    `PlotOutEnemiesForNextHour`:

    ```
    a = 실내곡선(t) - 1 + |마감까지 남은 날 - 3| / 1.6
    마릿수 = Lerp(a + 마감보정 - r, a + r, 난수)
           → 반올림, 최소 마릿수 ~ 20으로 자름
    ```

    - `r` = 스폰 수 흔들림(`spawnProbabilityRange`)
    - 마감 보정은 아래쪽 범위에만 붙습니다.
    - 침공 레벨이면 +2
        - 침공 = 호두까기 인형 파워 20 / 비축 벌레 파워 30 레벨
    - 빈 벤트 수를 넘을 수 없습니다.

=== "외부(야간)"

    `SpawnEnemiesOutside`:

    ```
    a = 외부곡선(t)  (소수 둘째 자리에서 버림)
    마릿수 = Next(a + 마감보정 - 3, a + 3)
           → 최소 마릿수 ~ 20으로 자름
    ```

=== "외부(주간)"

    ```
    마릿수 = Next(c - r, c + r)  → 0 ~ 20으로 자름
    ```

    - `c` = 주간곡선(t), `r` = 주간 흔들림
    - 몬스터의 떠나는 시각이 지나면 스폰하지 않습니다.

### 최소 마릿수를 올리는 것

| 원인 | 효과 |
|---|---|
| 일식 | 실내·외부 최소 = 위성 값 (1~4) |
| 장치(코어) 뽑기 | 70% 확률로 실내 최소 2. 잠든 올드 버드가 모두 깨어남 |
| 폐품을 많이 찾음 | 최소 1 (조건은 아래) |

**폐품을 많이 찾음** 조건

마감 D-2 이하이고, 최소 마릿수가 0일 때만 봅니다. 아래 중 하나면 됩니다.

1. 찾은 폐품 가치 ≥ 할당량, 그리고 시각 > 0.3
2. 맵 전체 폐품 가치의 65% 넘게 찾음
3. 연속 생존 5일 이상

"찾음" = 배 밖에 있던 폐품을 **처음 집을 때** 가치가 더해집니다.

## 종류 뽑기

가중치에 비례해 뽑습니다(`GetRandomWeightedIndex`).

```
가중치 = 희귀도 × 시간 곡선(시각)
```

가중치가 바뀌는 경우:

| 조건 | 가중치 |
|---|---|
| 파워 초과, 최대 수 도달, 스폰 꺼짐 | 0 |
| 실내에서 그날 처음 나오는 종류 | 다양성 파워 확인 |
| 침공 종류 | 100 |
| 침공 중 다른 종류 | ×0.075 |
| 던전 종류가 몬스터 선호 던전과 같음 | Min(×1.5, +50) |

## 벤트 대기

- 호스트가 벤트에 배정하는 **순간** 마릿수와 파워가 올라갑니다(`AssignRandomEnemyToVent`).
- 배정 결과(벤트, 종류, 시각)는 모든 클라이언트에 전달됩니다.
    - **클라이언트도 어느 벤트에서 무엇이 언제 나올지 알 수 있습니다.**
- 나올 시각이 가까워지면 벤트에서 **끼익거리는 소리**가 나고 점점 커집니다.
    - 기준: 남은 시간 < `enemyType.timeToPlayAudio`
    - 실내에서 이 소리가 들리면 곧 몬스터가 나온다는 뜻입니다.

!!! bug "클라이언트의 벤트 목록은 비어 있음"
    `RoundManager.allEnemyVents`는 호스트에서만 채워집니다.
    클라이언트에서 쓰려면 `FindObjectsOfType<EnemyVent>()`로 직접 찾아야 합니다.

## 스폰 난수 시드

| 난수 | 시드 | 용도 |
|---|---|---|
| `EnemySpawnRandom` | seed + 40 | 실내 마릿수·시각·벤트·종류 |
| `OutsideEnemySpawnRandom` | seed + 41 | 외부(야간) |
| `WeedEnemySpawnRandom` | seed + 42 | 은폐 수풀 몬스터 |
| `DaytimeEnemySpawnRandom` | seed + 43 | 외부(주간) |
| `AnomalyRandom` | seed + 5 | 위치, 폐품, 잠긴 문 등 공용 |

- 종류별 난수가 따로라서, **죽은 몬스터가 없으면** 하루 스폰의 종류·마릿수를 미리 계산할 수 있습니다.
- 위치는 공용 난수라 예측이 어렵습니다. 올드 버드 둥지만 예외입니다.

### 유령 소녀가 난수를 초기화함

- 유령 소녀가 나오면(`DressGirlAI.Start`) 스폰 난수를 다시 만듭니다.
- 이걸 막는 플래그(`hasInitializedLevelRandomSeed`)를 켜는 코드가 **어디에도 없습니다.**
- 그래서 유령 소녀가 나올 때마다 위 난수가 전부 처음부터 다시 시작합니다.

→ 유령 소녀가 나온 뒤의 배치는 원래 순서와 달라집니다.

## 잠든 올드 버드

1. 레벨을 만들 때 호스트가 하루 외부 스폰을 미리 돌려 봅니다(`PredictAllOutsideEnemies`).
2. 올드 버드가 뽑힐 때마다 **둥지**를 하나씩 놓습니다.
3. 실제 올드 버드가 스폰되면 첫 둥지 자리로 옮겨지고 둥지는 사라집니다.
    - → **앞 둥지부터 깨어납니다.**
4. 장치(코어)를 뽑으면 둥지마다 올드 버드가 바로 스폰됩니다.

## 첫 외부 스폰의 함정

- 첫 외부 스폰은 모든 외부 종류의 스폰 수(`numberSpawned`)를 0으로 되돌립니다.
- 레벨을 만들 때 미리 계산하며 올려 둔 값을 지우는 것입니다.
