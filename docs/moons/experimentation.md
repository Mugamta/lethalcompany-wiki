# 41-익스페리멘테이션 (Experimentation)

!!! info "읽는 법"
    - 값은 게임 에셋(`SelectableLevel`·`EnemyType`)에서 직접 읽었습니다.
    - 시간대별 %는 그 시각에 **어떤 종류가 뽑히는지**의 확률입니다. (희귀도 × 시간 곡선)
    - 파워·최대 수·다양성 제한으로 빠지는 경우는 반영하지 않았습니다.
    - 규칙은 [몬스터 스폰](spawning.md)에 있습니다.

| 은폐 수풀 | 생길 수 있음 |

## 시간대별 스폰 수 곡선

스폰할 때마다 이 값을 기준으로 마릿수를 정합니다.

- 실내 = 값 − 1 + 마감 보정 ± 흔들림
- 외부 = 값 ± 3
- 주간 = 값 ± 주간 흔들림
- 첫 실내 스폰은 06시 값으로 계산하지만, 실제로는 약 07:25에 일어납니다.
