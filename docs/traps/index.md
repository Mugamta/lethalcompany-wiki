# 함정

시설 안에 놓이는 함정 네 가지입니다.
바깥의 위험(늪·물·벼락)은 [환경 요소](../environment/index.md)에 있습니다.

## 함정 개수

호스트가 시드(`randomMapSeed + 587`)로 정합니다(`SpawnMapObjects`).

- 위성마다 함정 종류별 **개수 곡선**이 있고, 난수로 곡선을 읽어 개수를 정합니다.
- 광산 던전에서는 광산에 못 놓는 종류를 건너뜁니다.
- 챌린지 문(45%)에서만 한 종류가 2배(최대 150)가 됩니다.

!!! info "함정 수와 상관없는 것"
    날씨, 위험도, 인원, 할당량, 마감

**실제로는 곡선보다 적을 수 있습니다.**

- 함정끼리 5m 안에 겹치면 다시 시도하지 않고 건너뜁니다.
- 놓을 자리(스포너)가 모자라도 줄어듭니다.

### 위성별 개수

위성 에셋의 곡선을 직접 계산한 값입니다.
곡선 끝에서 값이 급하게 오르기 때문에, 평소엔 적다가 가끔 **유독 많은 날**이 나옵니다.

## 증기 누출 (증기 밸브)

뿜어져 나온 김이 시야를 가립니다. **피해는 없습니다.**

### 터지는 시각

- 밸브마다 **75%** 확률로 그날 터집니다. 나머지 25%는 안 터집니다.
- 터지는 시각은 09:36 ~ 24:00 사이입니다(`normalizedTimeOfDay` 0.2~1).
- 시드(`randomMapSeed + 513`)로 정하므로 **모든 플레이어에게 같은 시각**입니다.

### 터지면

- 그 자리에 **안개**가 생겨 12초에 걸쳐 커집니다.
- 근처 플레이어 헬멧에 김이 서리고 "VISIBILITY LOW!" 경고가 뜹니다.
- 밸브를 돌려 잠그면 안개가 4초에 걸쳐 줄어듭니다.

밸브 수는 던전의 방 조각(파이프 방)에 따라 정해집니다.

## 지뢰

| 항목 | 값 |
|---|---|
| 터지는 때 | 밟았다가 **발을 뗄 때** |
| 즉사 거리 | **5.7m** |
| 피해 거리 | 6m 안 피해 **50** |
| 몬스터 | 4.5m 안 피해 6 |
| 연쇄 | 6m 안 다른 지뢰가 0.2초 뒤 터짐 |

**밟는 것**

- 플레이어, 아이템, 시체
- **몬스터는 안 밟힙니다.**
- 지뢰 위에서 순간이동해 사라져도 터집니다.

**거리와 벽**

- 거리는 폭발 지점(지뢰 위 1m)에서 플레이어 발까지입니다.
- 4m보다 멀면서 벽에 가려 있으면 피해가 없습니다.

**그 밖에**

- 터미널 코드로 꺼 두면, 그동안은 발을 떼도 안 터집니다.
- 피해 50은 50 미만이 아니므로 [버티기](../player/index.md#버티기-조건)가 걸리지 않습니다.
    - 체력이 50 이하면 죽습니다.

## 터렛

| 단계 | 동작 |
|---|---|
| 감시 | 좌우로 돌며 **30m** 안 플레이어를 찾음 |
| 충전 | 찾으면 경고음 후 **1.5초** 조준 |
| 발사 | **0.21초마다** 피해 **50** |
| 놓침 | 시야가 **2초** 끊기면 감시로 돌아감 |
| 광폭 | 맞으면 1.3초 뒤 **9초 동안** 빙글 돌며 난사 |

- **감시**
    - 회전 범위는 75°입니다(프리팹 값, 코드 기본값 45°).
    - 7초마다 방향을 바꾸고, 0.25초마다 광선 7개로 찾습니다.
- **충전**: 조준이 끝날 때 시야가 끊겨 있으면 취소됩니다.
- **발사**
    - 체력이 50 이하면 **즉사**합니다.
    - 체력 100이면 두 발(약 0.4초)에 죽습니다: 100 → 50 → 즉사
- **광폭**: 삽 등으로 때리면 됩니다.
- 몬스터에게는 피해를 주지 않습니다.
- 발사음(15m / 0.9)은 범위 안 눈 없는 개를 바로 분노시킵니다.

## 천장 덫

천장에서 가시판이 내려찍습니다.

- 내려찍힐 때 그 아래 있으면 **즉사**합니다. 시체는 가시에 꽂힙니다.
- 처치 가능한 몬스터도 죽습니다.

### 두 가지 방식

덫마다 시드로 방식이 정해집니다.

| 방식 | 확률 | 동작 |
|---|---|---|
| 주기형 | 80% | 일정 간격마다 내려찍음 |
| 감지형 | 20% | 레이저(**4.4m**)에 플레이어가 닿으면 내려찍음 |

입구 7m 안에 있는 덫은 항상 주기형입니다.

**주기형 간격**

| 확률 | 간격 |
|---|---|
| 10% | 0.8~26초 |
| 10% | 0.7~2.1초 |
| 80% | 0.8~10.8초 |

- 입구 근처 덫은 최소 1.25초입니다.
- 8m 안에 몬스터가 있고 14m 안에 플레이어가 없으면 쉽니다. 몬스터를 덜 죽이려는 것입니다.
- 입구 7m 안 덫은 누가 입구를 쓴 직후 1.2초 동안 멈춥니다.

**감지형**

- 레이저에 **처음 닿는 것**이 플레이어여야 합니다. 벽·물건에 가리면 안 걸립니다.
- 내려찍은 뒤 1.2초는 다시 감지하지 않습니다.

## 터미널 코드로 끄기

함선 터미널에 함정 옆 영숫자 코드를 치면 잠시 꺼집니다(프리팹 값).

| 함정 | 꺼지는 시간 | 다시 칠 수 없는 시간 |
|---|--:|--:|
| 터렛 | 7초 | 1.5초 |
| 천장 덫 | 7초 | 1.5초 |
| 지뢰 | 3.2초 | 1.5초 |
