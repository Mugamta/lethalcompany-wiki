# 폐기물

시설 안팎에서 주워 회사에 파는 물건(`Item.isScrap`)입니다.
값은 게임 에셋(`Item`)에서 직접 읽었습니다.

## 가치는 이렇게 정해집니다

```
가치 = (int)(Random(minValue, maxValue) × 0.4)
```

- 0.4는 `RoundManager.scrapValueMultiplier`(씬 값)입니다. 아래 표의 가치는 이미 곱한 값입니다.
- 난수는 레벨 시드(`AnomalyRandom`)라서, 같은 시드면 같은 가치가 나옵니다.
- 선물 상자 안 아이템은 (min + 25 ~ max + 35) × 0.4입니다.

### 한 종류만 나오는 날

4.2%(21/500) 확률로, 그날 폐기물이 **전부 한 종류**가 됩니다.

- 가치는 **50~170 사이로 잘립니다.**
- 양손이거나 희귀도 5 미만인 종류가 뽑히면 최대 두 번 다시 뽑습니다.
- 그래도 안 맞으면 60% 확률로 취소됩니다.

## 열 설명

무게(lb)
:   Round((`weight` − 1) × 105).
    이동속도·스태미나에 주는 영향은 [플레이어](../player/index.md#이동속도와-무게)에 있습니다.

양손
:   `twoHanded`. 들고 있는 동안 다른 물건을 못 줍고, 슬롯도 못 바꿉니다.
    상호작용 지점마다 양손 허용 여부가 따로 있어 일부는 막힙니다.

전도성
:   `isConductiveMetal`. 뇌우 때 [금속 벼락](../environment/index.md#금속-벼락)의 대상입니다.

배터리
:   `requiresBattery`. 함선 [충전기](../ship/index.md#배터리-충전기)로 채웁니다.

상호작용
:   프리팹에 붙은 스크립트로 분류했습니다.

    - **사용**: 좌클릭 등으로 동작
    - **자동**: 들거나 떨어뜨리면 저절로 소리·효과
    - **—**: 들고 옮기기만 가능

나오는 곳
:   폐기물이 나오는 위성입니다. 위성 이름은 앞 두 글자로 줄였습니다.
    (익스 = 익스페리멘테이션, 오펜 = 오펜스, 타이 = 타이탄, 엠브 = 엠브리온 등)

    위성별 확률은 각 [위성](../moons/index.md) 문서의 폐기물 표에 있습니다.

### 알아 둘 것

- **Zed Dog**과 **고무 오리**는 가치 범위가 아주 넓습니다(0~199, 2~99).
- **가면(희극·비극)**
    - 얼굴에 대고 있으면(손에 든 지 10초 뒤부터 5초마다 65%) 달라붙고, 5초 뒤 [가면 쓴 사람](../creatures/masked.md#가면-폐기물)이 됩니다.
    - 뒤집어쓰는 순간 소리(8m / 0.6)도 납니다.
- **부활절 달걀**과 **수제 섬광탄**은 섬광탄과 같은 스크립트(`StunGrenadeItem`)지만 터지는 방식이 다릅니다. (프리팹 값)

| 아이템 | 터지는 때 | 확률 |
|---|---|--:|
| 섬광탄 (상점) | 핀을 뽑고 2.25초 뒤 | 100% |
| 수제 섬광탄 | 핀을 뽑고 **0.18초** 뒤. 던지기 전에 손에서 터질 수 있음 | 100% |
| 부활절 달걀 | 던져서 땅에 닿을 때 (핀 없음) | **17%** |

- 부활절 달걀의 확률은 집을 때마다 `Random(randomMapSeed + 10 + 집은 위치 x + z)`로 정합니다.
    - `Next(0, 100) ≤ 16`이라 16%가 아니라 17%입니다.
    - 시드가 정해져 있어서 같은 날 같은 자리에서 집으면 결과도 같습니다.
- 소리 나는 폐기물의 범위·크기는 [소리와 눈 없는 개](../creatures/noise.md#아이템)에 있습니다.
