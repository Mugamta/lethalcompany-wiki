# 플레이어

플레이어(`PlayerControllerB`)의 체력, 스태미나, 이동, 상태입니다.
프리팹 값은 게임 에셋에서 직접 읽었습니다.

| 프리팹 값 | 값 |
|---|---|
| 체력 `health` | 100 |
| 걷기 속도 `movementSpeed` | 4.6 m/s |
| 스태미나 시간 `sprintTime` | 11초 |
| 점프 힘 `jumpForce` | 13 |
| 사다리 속도 `climbSpeed` | 3 |
| 줍기 거리 `grabDistance` | 3m |

`sprintTime`은 코드 기본값이 5지만, 프리팹에 11로 저장돼 있습니다.

## 체력

| 규칙 | 내용 |
|---|---|
| 최대 | 100 |
| 버티기 | 죽을 피해를 받아도 체력 5로 남음 (조건은 아래) |
| 중상 | 체력 10 미만. 다리를 절고 피를 흘림 |
| 자연 회복 | 체력 20 미만일 때만 1초에 1씩, 20까지 |
| 스태미나 보너스 | 10 이상 피해를 받으면 스태미나가 피해/125만큼 **찹니다** |

### 버티기 조건

다음을 모두 만족하면 죽지 않고 체력 5로 남습니다.

- 중상(`criticallyInjured`) 상태가 아님
- 받은 피해가 50 미만
- 즉사(`KillPlayer`)가 아님

체력이 20까지 회복되면 중상이 풀리고, 다시 버티기가 가능해집니다.

### 예시

- 썸퍼(40)에게 맞으면: 100 → 60 → 20 → **5**(버팀, 중상) → 다음 한 대에 죽음
- 터렛(50)은 체력 50 이하면 바로 죽입니다. 버티기가 걸리지 않습니다. ([터렛](../traps/index.md#터렛))

!!! note "다른 사람 체력 표시"
    다른 사람의 체력은 피해를 받을 때만 동기화됩니다(`DamageOnOtherClients`).
    그래서 자연 회복은 남에게 늦게 보일 수 있습니다.

## 스태미나

화면 왼쪽 위 원형 게이지입니다(`sprintMeter`, 0~1).

| 상황 | 초당 변화 | 걸리는 시간 |
|---|---|---|
| 달리기 | −carryWeight / 11 | 빈손 11초에 바닥 |
| 방해받으며 걷기 (거미줄·늪 등) | −0.5 / 11 | 22초에 바닥 |
| 가만히 서 있기 | +1 / 15 | 15초에 가득 |
| 걷기 | +1 / 20 | 20초에 가득 |
| 점프 | 한 번에 −0.08 | |

### 탈진

- 게이지가 0.1 밑으로 떨어지면 탈진(`isExhausted`)합니다.
- 0.2를 넘어야 풀립니다.
- 안 달리던 중 게이지 0.3 미만에서 달리기를 누르면 바로 탈진합니다.
- 탈진 중에는 달리기도, 점프도 못 합니다.

### 그 밖에

- 중상(체력 10 미만)이면 달릴 수 없습니다.
- 취한 상태(TZP)에서는 소모·회복에 곡선 배율이 붙습니다.
- 예: 무게 50 lb(carryWeight 약 1.48)면 11 / 1.48 ≈ **7.4초** 만에 바닥납니다.

## 이동속도와 무게

```
속도 = movementSpeed(4.6) / carryWeight
```

- 빈손 걷기 4.6 m/s, 달리기 약 10.35 m/s
- 가속도도 무게에 반비례합니다.
    - 달리기: 5 / (무게 × 1.5)
    - 걷기: 10 / 무게

### 속도에 곱해지는 것

| 조건 | 효과 |
|---|---|
| 늪에 빠짐 (`sinkingValue > 0.73`) | 0 |
| 웅크림 | ÷1.5 |
| 중상 (웅크리지 않을 때) | × `limpMultiplier` |
| 이동 방해 (거미줄·늪·물 등) | ÷(2 × hinderedMultiplier) |
| 취함 | ×(drunknessSpeedEffect/5 + 1) |
| 중독 (시체 증식 감염) | ×0.75 |
| 경사 | max(0.8, 1 + 경사 × 계수) |
| 달리기 | ×2.25 (서서히 바뀜) |

### 무게 표시

```
화면의 무게(lb) = Round(Clamp(carryWeight − 1, 0, 100) × 105)
```

아이템 하나의 무게(`itemProperties.weight`)도 같은 식으로 lb가 됩니다.

## 상태

### 하루 끝 칭호

이륙 후 결과 화면에 붙는 칭호입니다(`StartOfRound.WritePlayerNotes`).

- 통계는 착륙해서 문이 열릴 때 초기화됩니다.
- **혼자 할 때는 칭호가 안 붙습니다.**

| 칭호 | 기준 | 조건 |
|---|---|---|
| 가장 게으른 직원 | 걸음 수가 가장 적음 | 그 걸음 수가 10 초과 |
| 가장 피해망상이 심한 직원 | 고개 돌린 횟수가 가장 많음 | |
| 가장 많이 다친 직원 | 받은 피해 합이 가장 큼 | 살아 있는 사람만 |
| 가장 수익성이 높은 직원 | 함선에 가져온 폐기물 가치가 가장 큼 | 50 초과 |

원문은 차례로 "The laziest employee.", "The most paranoid employee.", "Sustained the most injuries.", "Most profitable"입니다.

**값이 오르는 방식**

- **걸음 수** (`stepsTaken`): 위치 동기화 때 일정 거리 넘게 움직이면 +1
    - 혼자: 약 0.49m
    - 근처에 사람 있음: 약 0.32m
    - 특수 동작 중: 약 0.24m
- **고개 돌림** (`turnAmount`): 시점 회전이 남에게 동기화될 때마다 +1. 두리번거릴수록 커집니다.
- **수익** (`profitable`)
    - 폐기물을 함선 안에 내려놓으면 더하고, 함선 밖에 내려놓으면 뺍니다.
    - 전날부터 함선에 있던 폐기물은 세지 않습니다.

!!! note "아무도 해당 안 될 때"
    "가장 피해망상"과 "가장 많이 다친"은 전원이 0이어도 붙습니다.
    이때는 바로 앞 칭호에서 뽑힌 사람이 받습니다. 코드가 순번 변수를 초기화하지 않기 때문입니다.

### 경험치

결과 화면의 경험치(`HUDManager.SetPlayerLevel`)입니다.

| 항목 | 값 |
|---|--:|
| 살아 돌아옴 | +10 |
| 죽음 | −3 |
| 가장 수익성 높음 | +15 |
| 전원 사망 | −5 |

합이 0보다 크면 `오늘 모은 폐기물 가치 / 맵 전체 폐기물 가치`를 곱합니다.

### 포자 감염 (시체 증식)

시체 증식종이 퍼뜨리는 감염입니다. 진행과 치료는 [시체 증식](../creatures/cadaver.md)에 있습니다.

- 감염되면 **중독**(`poison`) 값이 오릅니다. 이동속도 ×0.75, 화면 효과.
- 감염 **35% 초과**에서 죽으면 시체에서 시체 증식종이 생깁니다(`bloomOnDeath`).
- **100%**가 되면 발아가 시작되고, 끝까지 가면 터져 죽습니다.

### 그 밖의 상태

| 상태 | 값 | 효과 |
|---|---|---|
| 취함 | `drunkness` 0~1 | TZP. 속도·스태미나 배율, 화면 왜곡 |
| 이동 방해 | `isMovementHindered` | 거미줄·늪·물. 속도 ÷(2 × 배율) |
| 가라앉음 | `sinkingValue` 0~1 | 늪. 1이면 질식사 ([늪](../environment/index.md#늪)) |
| 물속 | `isUnderwater` | 머리가 잠기고 12초 뒤 익사 ([물](../environment/index.md#물)) |
| 공포 | `fearLevel` | 몬스터를 보거나 쫓기면 오름. 심장 소리 등 |

## 목소리 범위

- 팀원 목소리는 3D로 재생됩니다. 거리는 머리(카메라) 기준입니다.
- 거리 감쇠는 프리팹 값이라 코드에는 없습니다.
- 벽이나 몬스터에 막히면 소리가 먹먹해질 뿐, 들리는 거리는 그대로입니다.
- **무전기**: 말하는 쪽과 듣는 쪽이 모두 무전기를 들고 있으면 거리와 상관없이 들립니다.
    - 송신 중에는 무전기 **9m** 안의 다른 소리(몬스터·아이템 효과음 등)도 같이 전달됩니다(프리팹 값 `recordingRange`, 코드 기본값 6).
    - 볼륨은 거리에 따라 1 → 0으로 줄어듭니다(12m에서 0). 16m 넘게 멀어지면 끊깁니다.
- 죽은 사람 목소리는 산 사람에게 안 들립니다.
- 산 사람 목소리는 관전자에게 0.8 볼륨으로 들립니다.
- 마이크 음량이 직전 순간(최근 약 0.35초) 평균의 3배를 넘으면 몬스터가 듣습니다. ([소리](../creatures/noise.md#플레이어))

## 전도성 아이템

- `Item.isConductiveMetal`은 켜짐/꺼짐뿐입니다. 정도는 없습니다.
- 켜진 아이템은 뇌우의 [금속 벼락](../environment/index.md#금속-벼락) 대상입니다.
- 목록은 [폐기물](../scrap/index.md#폐기물-목록)과 [상점 아이템](../ship/index.md#상점-아이템) 표의 "전도성" 열에 있습니다.

## 코드 참고

- **사망**: `PlayerControllerB.KillPlayerClientRpc(playerId, causeOfDeath)`. 모든 클라이언트에서 실행됩니다.
- **시체**: `deadBody` (`isInShip`, `grabBodyObject`). 가면에게 당했으면 `redirectToEnemy is MaskedPlayerEnemy`.
- **배터리 잔량**: `insertedBattery.charge`, `itemProperties.requiresBattery`
- **스프레이 잔량**: private `SprayPaintItem.sprayCanTank`
