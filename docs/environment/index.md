## 늪

밟고 서 있으면 가라앉습니다(`QuicksandTrigger`, 물 아님).

| 항목 | 값 |
|---|---|
| 이동속도 | **÷3.2** |
| 가라앉는 속도 | 초당 +0.21 |
| 움직일 수 없음 | 가라앉음 0.73 초과 |
| 죽음 | 가라앉음 1 → **질식사** (시체 안 남음) |
| 빠져나오면 | 초당 −0.75 |

- 서 있기 시작해서 약 **4.8초** 만에 죽습니다.
- 이동속도 ÷3.2 = ÷(2 × 1.6). 1.6은 `movementHinderance`입니다.

### 가라앉는 조건

다음을 모두 만족할 때만 가라앉습니다.

- 땅에 서 있음 (점프로 공중에 있으면 안 가라앉음)
- 지형·흙 같은 표면 위
- 사다리·함선·엘리베이터 위가 아님
- 특수 동작 중이 아님

### 늪이 생기는 곳

- **비가 오면** 바깥에 늪이 5~14개 생깁니다. 7% 확률로 5~29개.
    - 바깥 AI 노드 주변 30m 안에 놓입니다.
    - 시드(`randomMapSeed + 2`)로 정하므로 모든 클라이언트가 같은 자리입니다.
- 씬에 미리 놓인 늪도 있습니다.
    - 익스페리멘테이션 36개, 마치 3개, 애더먼스 2개

## 물

머리가 잠기면 숨이 줄어듭니다. 물에서는 가라앉지 않습니다.

| 항목 | 값 |
|---|---|
| 이동속도 | 바깥 물 ÷1.4, 실내 물 ÷1.2 |
| 숨 | 머리가 물속이면 **12초** 만에 익사 |
| 경고 | 숨 30% 이하에서 "Oxygen critically low!" |
| 회복 | 머리가 물 밖이면 초당 +1 (최소 10%부터) |

- 익사하면 시체가 남습니다.
- 씬에 놓인 물: 마치 5곳, 보우 3곳, 애더먼스 2곳
- [홍수](../weather/index.md#홍수-flooded) 날씨의 물도 같은 규칙입니다.
- 바깥 물에 낙하 속도 4 넘게 떨어지면 작은 물보라, 17 넘으면 큰 물보라가 튑니다.

## 벼락

뇌우 날씨에만 칩니다. 성격이 다른 **두 가지 벼락**이 있습니다.

| | 무작위 벼락 | 금속 벼락 |
|---|---|---|
| 노리는 곳 | 바깥 아무 곳 | 전도성 물건 |
| 계산 | 모든 클라이언트 (같은 결과) | 호스트만 |
| 예측 | 시드로 가능 | 불가능 |
| 경고 | 없음 | 정전기 파티클 |

### 무작위 벼락

**위력**: **2.4m 안 즉사, 5m 안 피해 50**

**시드**

- 처음 시드는 `randomMapSeed`, 첫 벼락은 7초 뒤입니다.
- 게임 시간이 10초 경계를 넘을 때마다 시드를 다시 만듭니다.
    - 새 시드 = 10초 단위로 내린 시간 + `randomMapSeed`

**벼락마다**

1. 60% 확률이고 (간격 × 날씨 세기) < 3이면 **직전 자리에 또** 칩니다.
2. 아니면 바깥 AI 노드 하나를 고르고 ±7.5m 흔듭니다.
3. 다음 벼락까지의 간격:

```
Clamp(Next(−5, 110) × 0.25, 0.6, 110) / Clamp(날씨 세기, 1, 100)
```

### 금속 벼락

**호스트만** 계산하고, 시드가 없어 예측할 수 없습니다.

1. 날씨 시작 15초 뒤, 전도성 물건 목록을 **한 번만** 모읍니다.
2. 4초마다 대상을 고릅니다.
    - 실내·함선 안이 아닌 것 중 플레이어와 가까운 것
3. 타이머를 정합니다: 1~20초. 누가 들고 있으면 최소 4초.
4. 타이머가 10초 아래로 내려가면 **정전기 경고**가 뜹니다.
    - 파티클이 튀고, 든 사람에게 팁이 뜹니다.
5. 0이 되면 칩니다. 단, 그 물건이 **실내에 있으면** 취소하고 다른 대상을 고릅니다.

!!! warning "경고 후 실내에 갔다 나오면"
    실내에 있는 동안 파티클이 꺼지고, 다시 나와도 켜지지 않습니다.
    그런데 타이머는 계속 돕니다. **시간 전에 나오면 경고 없이 맞습니다.**

- 바깥 집·지붕 아래는 보호해 주지 않습니다. 시설 안(`isInFactory`)인지만 봅니다.
- 전도성 물건 목록은 [폐기물](../scrap/index.md)과 [상점 아이템](../items/index.md#아이템-목록) 표의 "전도성" 열에 있습니다.

## 운석

날씨와 상관없는 드문 사건입니다.

| 항목 | 값 |
|---|---|
| 확률 | 하루 **0.7%** (7/1000) |
| 시작 시각 | 약 06:54~20:13 |
| 즉사 거리 | 운석 크기 |
| 피해 거리 | 크기 × 1.4 (최대 +12) |
| 피해 | 40 |

- 호스트가 시드(`randomMapSeed + 28`)로 정합니다(`DecideRandomDayEvents`).
