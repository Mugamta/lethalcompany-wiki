# 몬스터 감지·추격

몬스터가 플레이어를 언제 알아채고 쫓기 시작하는지, IL을 직접 디스어셈블해서 확인한 값입니다. 단위는 m.

!!! tip "관련 문서"
    소리로 감지하는 몬스터(눈 없는 개 등)는 [소리와 눈 없는 개](noise.md)를 보세요.

## 읽는 법 (공통 규칙)

- **몬스터 시야** `CheckLineOfSightForPlayer(각도, 거리, 근접)`:
  - 몬스터 눈(`eye`) 정면에서 **좌우 각각 '각도'°** 안이면 보인다 (45 → 전체 90° 부채꼴, 180/360 → 모든 방향).
  - **'근접' 거리 안이면 각도와 상관없이** 보인다 (뒤에 있어도 들킴). -1이면 없음.
  - 벽에 막히면(Linecast) 안 보인다.
- **안개 날씨(Foggy)**: 외부 몬스터는 `canSeeThroughFog`가 아니면 시야 거리가 **최대 30m**로 잘린다.
- `TargetClosestPlayer(..., 시야필요=true)`는 거리 **40m 고정**으로 시야를 검사한다. 시야필요=false면 **거리 제한 없음**(시설 안 가장 가까운 플레이어).
- "플레이어가 몬스터를 봄" 조건(`HasLineOfSightToPosition`)은 플레이어 카메라 기준 각도·거리다.
- 함선 안(문 닫힘), 다른 몬스터에게 잡힌 상태, 죽은 상태는 대상에서 빠진다(`PlayerIsTargetable`).

## 참고: 플레이어가 내는 소리 (개·소리 감지 몬스터용)

- 걷기 발소리: 범위 17m, 크기 0.4 / 달리기: 범위 22m, 크기 0.6.
- 벽 사이에 있으면 크기와 범위가 절반. 크기 0.25 미만이면 개는 무시.

## 참고: 몬스터가 내는 소음 (개가 듣는 것)

`RoundManager.PlayAudibleNoise`를 부르는 곳만 개에게 들린다(IL 확인). 대부분의 몬스터 소리는 오디오 재생만이라 안 들림.
즉시 분노 거리 = 18 × 크기 (범위를 넘을 수 없음). 벽 너머면 절반.

| 몬스터 | 소리 나는 순간 | 범위 / 크기 | 즉시 분노 거리 |
|---|---|---|---|
| 개코 매 | 일정 속도 이상으로 움직일 때 소리 | 7m / 0.4 | 7.2m → 들리면 사실상 즉시 |
| 개코 매 | 플레이어·몬스터를 때릴 때 | 8m / 0.7 | 범위 전체 |
| 만티코일 | 울음 | 12m / 0.6 | 10.8m |
| 튤립 뱀 | 킥킥 웃음 | 10m / 0.7 | 범위 전체 |
| 납치 여우 | 짝 부르는 소리 | 20m / 0.6 | 10.8m |
| 납치 여우 | 죽을 때 / 몬스터와 부딪힘 | 20m / 0.7, 8m / 0.6 | 12.6m / 범위 전체 |
| 거대 키위 | 쪼기 공격 | 15m / 0.85 | 범위 전체 |
| 거대 키위 | 나무 쪼기 | 18m / 0.5 | 9m |
| 거대 키위 | 문 비틀어 열기 | 15m / 0.9 | 범위 전체 |
| 배회 메뚜기 | 떼 지어 있을 때 | 8m / 0.35 | 6.3m (떠날 때 0.2는 무시) |
| 스포어 도마뱀 | 발 구르기 | 8m / 0.8 | 범위 전체 |
| 덤퍼 | 벽에 부딪힘 | 8m / 0.75 | 범위 전체 |
| 브래컨 | 분노 상태로 바뀔 때 | 7m / 0.8 | 범위 전체 |
| (터렛) | 발사 | 15m / 0.9 | 범위 전체 |

- 개가 무시: 키위 noiseID 675189(12m/0.6), 몬스터 공용 애니메이션 소리 `PlayAudioAnimationEvent`(noiseID 546).
- 소음 이벤트 없음: 올드 버드, 거인, 가면 쓴 자, 개 자신.
- 개는 바깥에 있으므로 실제로 문제 되는 건 바깥 몬스터(개코 매, 만티코일, 튤립 뱀, 여우, 키위, 메뚜기).

## 대상(어그로) 읽을 때 주의

- 몬스터가 노리는 사람은 `EnemyAI.inSpecialAnimationWithPlayer`(잡고 있음) → 없으면 `targetPlayer`입니다.
- 그런데 **거인·납치범 여우 등 많은 몬스터는 추격이 끝나도 `targetPlayer`를 비우지 않습니다.** 정확히 알려면 상태 번호(`currentBehaviourStateIndex`)가 "추격" 상태인지 같이 봐야 합니다. 상태 번호는 [몬스터 체력·공격·상태](enemy-combat.md#몬스터별-상태-번호) 참고.
- AI 소유자(보통 호스트)에서 정해지므로 다른 클라이언트에는 종류에 따라 늦게 또는 안 전달될 수 있습니다.
