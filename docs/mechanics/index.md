## 자주 쓰는 용어

시드 (`randomMapSeed`)
:   레벨마다 정해지는 정수. 모든 클라이언트가 같은 값을 받습니다. 게임은 `System.Random(시드 + 고정값)`으로 용도별 난수를 만들기 때문에, **같은 시드면 같은 결과**가 나오는 것이 많습니다(폐품 배치, 증기 밸브 시각, 실내 안개, 늪 위치 등).

호스트 / 클라이언트
:   방장 컴퓨터가 서버입니다. 몬스터 스폰, 몬스터 AI(대부분), 금속 벼락 같은 판정은 호스트에서만 하고 결과만 RPC로 전달합니다.

`normalizedTimeOfDay`
:   하루를 0~1로 나타낸 시각. 0.63(약 오후 5:20)부터 해 질 녘(Sundown)입니다.

`currentDayTime`
:   하루 시작부터 흐른 게임 초. 벤트 스폰 시각이 이 단위입니다.
