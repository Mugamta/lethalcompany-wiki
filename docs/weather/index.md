# 기상

## 날씨별 효과

| 날씨 | 효과 |
|---|---|
| 맑음 | 없음 |
| [비](#비-rainy) | 바깥에 늪이 생김 |
| [뇌우](#뇌우-stormy) | 벼락이 떨어짐 |
| [안개](#안개-foggy) | 외부 몬스터 시야 최대 30m |
| [홍수](#홍수-flooded) | 바깥 수위가 하루 동안 오름 |
| [일식](#일식-eclipsed) | 처음부터 몬스터가 많이 나옴 |

!!! info "날씨와 상관없는 것"
    - **폐기물 가치·개수**는 날씨와 무관합니다.
    - **함정 개수**도 날씨와 무관합니다. ([함정](../traps/index.md#함정-개수))

- 게임에 먼지 구름(DustClouds) 날씨도 있지만, 어느 위성에도 나오지 않습니다.
- 위성마다 나오는 날씨와 세기는 [위성](../moons/index.md) 문서에 있습니다.

## 비 (Rainy)

- 바깥에 **늪**이 5~14개 생깁니다. 7% 확률로 5~29개.
- 늪 규칙은 [늪](../environment/index.md#늪)에 있습니다.

## 뇌우 (Stormy)

두 종류의 벼락이 떨어집니다.

- **무작위 벼락**: 아무 곳에나. 2.4m 안 즉사, 5m 안 피해 50.
- **금속 벼락**: 전도성 물건을 노림.

자세한 규칙은 [벼락](../environment/index.md#벼락)에 있습니다.

## 안개 (Foggy)

- 외부 몬스터의 시야가 **최대 30m**로 잘립니다.
    - 안개를 꿰뚫어 보는 몬스터는 **페이오파**뿐입니다.
- 숲지기의 70m 시야도 30m로 잘립니다.
- 안개 짙기는 위성 값 범위에서 시드로 정합니다. 최소 4입니다.
    - 값(`meanFreePath`)이 작을수록 짙습니다.

## 홍수 (Flooded)

물 높이가 하루 동안 서서히 바뀝니다(`FloodWeather`).

```
목표 높이 = 시작 높이 + (globalTime / 1080) × 상승량
```

- 실제 수면은 초당 0.5m 이하로 목표를 따라갑니다.
- `globalTime`은 매일 100에서 시작합니다. 하루가 끝날 무렵 수면은 시작보다 약 상승량만큼 높습니다.
- 홍수 날에는 바깥 NavMesh를 물 높이에 맞춰 다시 굽습니다.
- 물속 이동·익사는 [물](../environment/index.md#물)에 있습니다.

**위성별 값**

| 위성 | 시작 높이 (y) | 상승량 |
|---|--:|--:|
| 익스페리멘테이션 | −4 | +5 |
| 어슈어런스 | −2 | +2 |
| 보우 | −6 | +6 |
| 오펜스 | −4 | +5 |
| 애더먼스 | −24 | +13 |
| 다인 | −11 | **−10** (내려감) |
| 아터피스 | −10 | +6 |

## 일식 (Eclipsed)

내부·외부 **최소 스폰 수**가 위성 값으로 오릅니다(`EclipseWeather`).

| 위성 | 최소 스폰 수 |
|---|--:|
| 익스페리멘테이션, 어슈어런스, 보우 | 1 |
| 마치 | 2 |
| 애더먼스, 렌드, 타이탄, 아터피스 | 3 |
| 오펜스, 다인, 엠브리온 | 4 |

- 스폰할 때마다 이 수 이상 나오려고 합니다. 벤트 수·파워 한도는 그대로입니다.
- 착륙하면 "Weather alert!" 경고가 뜹니다.

## 날씨가 정해지는 방식

전 위성의 날씨는 `StartOfRound.SetPlanetsWeather`에서 한꺼번에 정합니다.

**다시 뽑는 때**

- 하루가 지날 때
- 저장을 불러올 때
- **플레이어가 접속할 때** → 접속하면 전 위성 날씨가 바뀝니다.

**뽑는 순서** (`Random(randomMapSeed + 35)`)

1. 날씨가 붙을 위성 수를 정합니다.
    - 곡선(0~1 난수) × 배수 × (위성 수 − 3)
2. 배수는 보통 1입니다.
    - 2명 이상이고 연속 생존이 3의 배수 날(3, 6, 9…)이면 1.5~2.4
3. 그 수만큼 위성을 골라, 각 위성의 날씨 후보 중 하나를 붙입니다.
    - 첫 날(마감 D-3)의 익스페리멘테이션은 건너뜁니다.

**착륙 후**

- 고른 날씨와 날씨 세기가 현재 레벨에 적용됩니다(`SetToCurrentLevelWeather`).
- 건물 안 등 맵의 특정 구역(`AudioReverbTrigger`)이 날씨 효과를 켜고 끕니다.

## 실내 안개

날씨는 아니지만 시야를 가리는 현상입니다.

- 건물 안에서만 켜지며 시야가 짧아집니다.
- 시드(`randomMapSeed + 5781`)로 정하므로 모든 클라이언트가 같습니다.

| 경우 | 확률 |
|---|--:|
| 침공 레벨 (0.4%) | 20% |
| 그 밖 | 2% |
| 10월 23일 | 추가 확률 있음 |

증기 밸브의 국소 안개와는 별개입니다. ([증기 누출](../traps/index.md#증기-누출-증기-밸브))
