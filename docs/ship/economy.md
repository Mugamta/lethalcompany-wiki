# 돈·할당량·배송

## 초과 수당 (Overtime)

할당량보다 더 팔면 받는 보너스입니다(`TimeOfDay.SetNewProfitQuota`, 호스트).

```
초과 수당 = (판매액 합 − 할당량) / 5 + 15 × 남은 날
```

- **할당량을 채웠으면** 마감 전이라도 이륙할 때 계산합니다.
- 음수가 나오면 0으로 칩니다.

### 남은 날 계산

`daysUntilDeadline`은 이륙 **후** 값입니다.

- **마감 당일**에 팔면 남은 날이 −1이 됩니다.
    - → 초과분이 **$80 넘어야** 수당이 생깁니다.
- **마감 전(D-n)**에 회사에 가면, 회사에서는 시간이 안 흘러 날이 안 지납니다.
    - → 15 × n을 그대로 받습니다.

## 사망 벌금

이륙할 때 죽은 사람이 있으면 벌금을 냅니다(`HUDManager.ApplyPenalty`).
회사에서 죽어도 냅니다. 챌린지 문은 제외입니다.

| 죽은 사람 1명마다 | 벌금 |
|---|---|
| 시체를 못 가져옴 | 이륙 전 잔액의 **20%** |
| 시체를 함선에 가져옴 | 이륙 전 잔액의 **8%** |

- 잔액은 60 밑으로는 깎이지 않습니다. 원래 60 미만이면 그대로입니다.
- 시체가 함선 안에 있으면 회수로 칩니다(`DeadBodyInfo.isInShip`).
- 벌금을 먼저 내고, 그다음 초과 수당이 들어옵니다.

!!! warning "이륙할 때 함선 밖에 있으면"
    이륙하는 순간 함선 안에 없는 사람은 죽습니다(Abandoned).

## 배송 (터미널 주문)

- 주문 목록은 `Terminal.orderedItemsFromTerminal`입니다.
    - 다른 클라이언트에는 **개수만** 가고, 목록은 안 갑니다.
- 배송선(`ItemDropship`)의 타이머는 호스트에서만 돕니다.
- 쉬고 있는 배송선 위치는 착륙 지점이 아닙니다. 실제 착륙 지점은 `itemSpawnPositions`입니다.
- 배송선 음악(60m / 1.3)은 눈 없는 개를 부릅니다.

## 함선 안 폐품

- "함선 안" 표시(`isInShipRoom`, `isInElevator`)는 **내려놓을 때만** 바뀝니다.
    - 함선에서 들고 나가도 "함선 안"으로 남습니다.
    - 회사 계산대에 올린 폐품도 마찬가지입니다.
- 오늘 모은 폐품 가치는 `RoundManager.scrapCollectedInLevel`입니다. 착륙할 때 0이 됩니다.

## 폐품을 찾으면 스폰이 늘어남

- 함선 밖 폐품을 **처음 집을 때** 가치가 "찾은 폐품"에 더해집니다(`valueOfFoundScrapItems`).
- 마감이 가까울 때 많이 찾으면 실내 최소 스폰이 1로 오릅니다. ([스폰](../moons/spawning.md#최소-마릿수를-올리는-것))
