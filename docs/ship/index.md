# 함선

함선 안의 장치들입니다.
돈·할당량·배송은 [돈·할당량·배송](economy.md)에 있습니다.

## 문 유압장치

함선 문은 닫아 두는 동안 유압(화면의 %)을 씁니다(`HangarShipDoor.doorPower`).

| 상황 | 걸리는 시간 |
|---|---|
| 문 닫힘 (착륙 중) | 100% → 0%까지 **30초** |
| 문 열림 (또는 착륙 전) | 0% → 100%까지 **6.6초** |

- 30초는 함선 씬에 저장된 값입니다(`doorPowerDuration`). 코드 기본값은 20입니다.
- 회복 속도는 초당 1 / (30 × 0.22)입니다.

### 0%가 되면

- 문이 강제로 열립니다.
- **과열** 상태가 되어, 다시 100%가 될 때까지 버튼을 못 씁니다.

### 문을 닫으면

- 함선 안 플레이어는 몬스터 대상에서 빠집니다. ([감지·추격](../creatures/detection.md#그-밖의-공통-규칙))
- 함선 안에서 난 소리는 범위가 절반이 되고, 크기 0.9 미만이면 몬스터가 못 듣습니다. ([소리](../creatures/noise.md))

## 모니터 (레이더)

함선 모니터의 지도 화면입니다(`ManualCameraRenderer`).

**대상 바꾸기**

- 대상은 플레이어와 레이더 부스터입니다.
- 모니터 옆 버튼이나 터미널 `switch`로 다음 대상으로 넘깁니다. 모든 사람에게 같이 바뀝니다.

**화면에 보이는 것**

| 표시 | 조건 |
|---|---|
| 입구까지 점선 | 대상이 시설 안에 있을 때 |
| 함선 방향 화살표 | 대상이 바깥, 함선에서 16m 넘게 떨어짐 |
| 야간 투시 (밝게) | 보는 사람이 함선 안, 대상이 함선에서 20m 넘게 떨어짐 |
| 시체 위치 | 대상이 죽었고 시체가 있을 때 |

- **점선**은 대상 위치에서 정문까지의 경로입니다.
    - 광산은 엘리베이터 아래까지 그립니다.
    - 0.4초마다 다시 계산하고, 경로를 못 찾으면 2초마다 다시 시도합니다.
- 지도는 초당 20번 그립니다(씬 값). 모니터는 버튼으로 끄고 켤 수 있습니다.

## 단말기 (터미널)

명령을 쳐서 위성 이동, 상점 구매, 함선 장치 조작을 합니다.

| 명령 | 동작 |
|---|---|
| `moons` / 위성 이름 | 위성 목록, 이동 |
| `store` / 아이템 이름 | 상점 구매 → [배송선](economy.md#배송-터미널-주문)으로 도착 |
| `scan` | 폐기물 개수와 총가치 (아래 참고) |
| `switch [이름]` | 모니터 대상 변경 |
| `ping [이름]` | 레이더 부스터 소리 |
| `flash [이름]` | 레이더 부스터 섬광 |
| 영숫자 2자리 코드 | 보안문 열고 닫기, 함정 잠시 끄기 |
| `bestiary` | 스캔한 생명체 목록 |
| `storage` | 창고에 넣은 함선 장식 |

**코드로 함정 끄기** ([함정](../traps/index.md#터미널-코드로-끄기))

- 터렛·천장 덫: **7초**
- 지뢰: **3.2초**

### `scan`의 가치

- **궤도에서**: 함선 안 폐기물 가치의 정확한 합
- **착륙 중**: 함선 밖 폐기물의 **대략적인** 합. 대체로 실제보다 높게 나옵니다.

!!! note "착륙 중 `scan`이 부정확한 이유"
    폐기물마다 배율 0.4를 곱하기 **전**의 가격 범위에서 값을 뽑습니다(`Random(시드 + 91)`).
    그 뒤 실제 가치 −6×i ~ +9×i로 자릅니다. (i = 그 폐기물의 목록 순번)

    원래 범위가 실제보다 약 2.5배 크므로 높게 나오고, 목록 뒤쪽일수록 오차가 커집니다.

에셋 값입니다.

|---|--:|--:|---|:-:|--:|
| 무전기 | 10 | 0 | 820초 (켠 동안) | | 80% |
| 손전등 | 15 | 0 | 140초 | | 80% |
| 자물쇠 따개 | 20 | 11 | — | | 80% |
| 제초제 | 20 | 0 | — | | 80% |
| 프로 손전등 | 28 | 5 | 300초 | | 80% |
| 삽 | 30 | 14 | — | ✔ | 80% |
| 섬광탄 | 30 | 5 | — | | 80% |
| 벨트 가방 | 45 | 16 | — | | 70% |
| 스프레이 페인트 | 50 | 0 | — | | 80% |
| 붐박스 | 60 | 16 | 350초 | | 80% |
| 연장 사다리 | 60 | 0 | — | ✔ | 60% |
| 레이더 부스터 | 60 | 19 | — | ✔ | 80% |
| TZP 흡입제 | 80 | 0 | — | ✔ | 80% |

- **배터리**: 가득 찬 상태에서 켜 두고 쓸 수 있는 시간(`batteryUsage`)입니다.
- **무게(lb)** = Round((`weight` − 1) × 105)
- **할인**은 하루가 지날 때마다 다시 정해집니다(`SetItemSales`). 아이템마다 최대 할인까지 붙습니다.

??? note "영어 이름 (펼치기)"
    Walkie-talkie, Flashlight, Lockpicker, Weed killer, Pro-flashlight, Shovel, Stun grenade,
    Belt bag, Spray paint, Boombox, Extension ladder, Radar-booster, TZP-Inhalant, Zap gun, Jetpack
    (표 순서대로)

## 배터리 충전기

- 배터리 아이템을 들고 충전기를 쓰면 **0.75초 뒤 100%** 가 됩니다.
- 조금씩 차는 게 아니라 한 번에 가득 찹니다.
- 배터리 아이템이 아니면 아무 일도 없습니다.

## 순간이동기

| | 쿨타임 | 하는 일 |
|---|--:|---|
| 순간이동기 | **10초** | 모니터 대상을 함선으로 데려옴 |
| 역방향 순간이동기 | **210초** | 올라선 사람을 시설 안 무작위 위치로 보냄 |

- 쿨타임은 에셋 값입니다. 누르면 모든 클라이언트에서 쿨타임이 시작됩니다.
- 둘 다 **들고 있던 아이템을 떨어뜨립니다.**
- 역방향은 궤도, 던전 생성 중, 회사에서는 못 씁니다.
- 이번 세션에 이미 있었던 순간이동기(재구매, 창고에서 꺼냄)는 쿨타임 상태로 시작합니다.

## 그 밖에

- **함선 경적 줄**: 소리 30m, 크기 0.8. 눈 없는 개가 14.4m 안이면 바로 분노합니다. ([소리](../creatures/noise.md#배차량시설))
- **이륙**: 그 순간 함선 안에 없는 사람은 죽습니다. ([사망 벌금](economy.md#사망-벌금))
