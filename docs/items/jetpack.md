# 제트팩 (Jetpack)

**Jetpack** · 900 크레딧

등에 메고 날아다닙니다. 부딪히거나 공중에서 죽으면 위험합니다.

## 기본 정보

| 항목 | 값 |
|---|---|
| 무게 | **53 lb** |
| 배터리 | 50초 (분사하는 동안) |
| 전도성 | **있음** |
| 최대 할인 | 80% |

## 조작

- **좌클릭을 누르고 있으면** 분사합니다. 보는 방향이 아니라 **몸의 위쪽**으로 밀어 줍니다.
- 몸을 기울이면 그쪽으로 날아갑니다.

| 상태 | 추력 변화 |
|---|---|
| 분사 중 | 초당 +10 (최대 500) |
| 분사 안 함 | 초당 −50 |
| 땅에 닿음 (분사 안 함) | 바로 0 |

- 추력은 10, 50이 프리팹 값입니다(코드 기본값 4, 75).
- 실제로 미는 힘은 최대 400입니다.

## 죽는 경우

**부딪힘**

- 미는 방향 **4m** 안에 벽이 있고, (힘 − 벽까지 거리)가 **50**을 넘으면 즉사합니다.
- 오래 분사해 빨라진 상태로 벽·천장에 가까워지면 죽습니다.

**공중에서 죽으면 폭발**

- 분사 조작 중 든 사람이 죽으면 제트팩이 터집니다.
    - **5m** 안 즉사, **6m** 안 피해 50
- 터진 제트팩은 다시 못 씁니다.

## 경고음

| 경고음 | 조건 |
|---|---|
| 배터리 부족 | 분사 중, 배터리 15% 미만 |
| 충돌 경고 | 분사 중, 6m 안에 벽·물체 |

|---|--:|--:|
