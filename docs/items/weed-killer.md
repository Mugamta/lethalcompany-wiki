# 제초제 (Weed killer)

**Weed killer** · 20 크레딧

덩굴과 시체 증식 식물을 없애고, 크루저에 기름을 넣습니다.
스프레이 페인트와 같은 스크립트(`SprayPaintItem`)입니다.

## 기본 정보

| 항목 | 값 |
|---|---|
| 무게 | 0 lb |
| 배터리 | 없음 |
| 전도성 | 없음 |
| 최대 할인 | 80% |
| 용량 | 뿌리는 시간 합계 **15초** |

## 뿌리기

- **좌클릭을 누르고 있으면** 뿌립니다.
- 한 번 누를 때 **최대 0.5초**만 나옵니다. 버튼을 떼면 다시 채워집니다.
    - 흔들 필요는 없습니다. 떼었다 다시 누르면 됩니다.
- **산 직후 처음 누를 때는 나오지 않습니다.** 한 번 떼고 나서부터 나옵니다.
- 남은 양은 저장되어, 다음 날에도 이어집니다.
- 궤도에서는 덩굴·식물에 효과가 없습니다.

## 효과

| 대상 | 효과 |
|---|---|
| 덩굴 ([은폐 수풀](../environment/vain-shroud.md)) | 시설 밖에서. 앞 1.8m 지점 반경 2m 안의 가장 가까운 덩굴이 줄어들다 사라짐 |
| 시체 증식 식물 ([시체 증식](../creatures/cadaver.md)) | 시설 안에서. 같은 방식으로 가장 가까운 식물 하나 |
| 감염된 다른 사람 | 5m 안, 정면 40°. 감염 치료 (아래) |
| 크루저 기름 주입구 | 4.5m 안에서 주입구 5m 안을 맞히면 0.3초마다 아래 효과 |

- 덩굴·식물은 한 번에 하나씩 없앱니다.

**크루저**

- 차 체력이 덜 찼으면 체력 **+4**
- 가득 찼으면 **터보 +1** (최대 5)

**감염된 사람에게 뿌리면**

- 0.33초마다 감염 −10%, 체력 −8
- 감염이 100%에 이른 뒤(발아 중)에 맞으면 **바로 터집니다.**
- 자세한 내용은 [시체 증식 치료](../creatures/cadaver.md#치료)에 있습니다.
