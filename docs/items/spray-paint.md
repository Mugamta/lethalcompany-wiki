# 스프레이 페인트 (Spray paint)

**Spray paint** · 50 크레딧

벽·바닥·사람에 페인트를 칠합니다. 길 표시용입니다.

## 기본 정보

| 항목 | 값 |
|---|---|
| 무게 | 0 lb |
| 배터리 | 없음 |
| 전도성 | 없음 |
| 최대 할인 | 80% |
| 용량 | 뿌리는 시간 합계 **30초** |

## 조작

| 키 | 동작 |
|---|---|
| 좌클릭 누르고 있기 | 뿌리기 |
| Q | 흔들기 (+15%) |

- 뿌리려면 **흔들어 둔 양**이 있어야 합니다. 새 캔은 0이라 먼저 흔들어야 합니다.
- 흔든 양은 뿌리는 1초마다 10%씩 줄어듭니다. 가득 흔들면(Q 7번) 10초 뿌릴 수 있습니다.
- 흔든 양이나 용량이 0이 되면 멈추고 소리가 납니다.
- 남은 용량은 저장되어, 다음 날에도 이어집니다.

## 칠해지는 방식

- 카메라 앞 **7m** 안에 닿는 곳에 칠합니다.
- **0.08초**마다 한 점씩 찍습니다. 직전 점과 0.175m 안이면 건너뜁니다.
- 다른 플레이어와 시체에도 칠해집니다. 자기 몸에는 안 칠해집니다.
    - 사람에게 칠한 페인트는 함선 **샤워**로 지울 수 있습니다.
- 페인트는 모든 캔을 합쳐 **1000점**까지입니다. 넘으면 가장 오래된 점부터 옮겨 씁니다.
- 함선 밖에 칠한 페인트는 하루가 끝나면 사라집니다. 함선 안 페인트는 남습니다.
- 색은 그날의 시드(`randomMapSeed + 151`)로 정해집니다. 그날은 모든 캔이 같은 색입니다.

## 소리

- 몬스터는 뿌리는 소리를 **듣지 못합니다.**
    - 코드에 1초마다 소리(10m, 0.65)를 내는 부분이 있지만, 켜는 곳이 없어 실제로는 나지 않습니다.
