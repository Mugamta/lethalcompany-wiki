# 무전기 (Walkie-talkie)

**Walkie-talkie** · 10 크레딧

켜 둔 무전기끼리 거리와 상관없이 목소리를 주고받습니다.

## 기본 정보

| 항목 | 값 |
|---|---|
| 무게 | 0 lb |
| 배터리 | 820초 (켜 둔 동안 닳음) |
| 전도성 | 없음 |
| 최대 할인 | 80% |

## 조작

| 키 | 동작 |
|---|---|
| Q | 전원 켜기/끄기 |
| 좌클릭 누르고 있기 | 송신 (켜져 있을 때만) |

- 버튼을 떼도 최소 **0.2초**는 송신합니다.
- 주머니에 넣으면 불빛이 꺼집니다. 전원은 그대로입니다.
- 배터리가 다 되면 전원이 꺼집니다.

## 송신

- 송신하면 켜져 있는 다른 무전기 전부에 목소리가 전달됩니다. 거리 제한이 없습니다.
- 송신을 시작하고 끝낼 때 다른 무전기에서 삑 소리가 납니다.
    - 이 소리는 몬스터가 못 듣습니다. ([소리](../creatures/noise.md))
- 송신 중에는 무전기 **9m** 안의 다른 소리도 같이 전달됩니다.
    - 몬스터 소리, 아이템 효과음 등
    - 9m는 프리팹 값(`recordingRange`)입니다. 코드 기본값은 6입니다.
    - 볼륨은 거리에 따라 1 → 0으로 줄어듭니다(12m에서 0). 16m 넘게 멀어지면 끊깁니다.
- 송신하던 사람이 죽으면 다른 무전기에 사망 효과음이 납니다.
