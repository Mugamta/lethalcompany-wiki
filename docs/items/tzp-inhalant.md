# TZP 흡입제 (TZP-Inhalant)

**TZP-Inhalant** · 80 크레딧

들이마시는 동안 스태미나가 차고 빨라지지만, 취해서 화면이 흔들립니다.

## 기본 정보

| 항목 | 값 |
|---|---|
| 무게 | 0 lb |
| 배터리 | 없음 |
| 전도성 | **있음** |
| 최대 할인 | 80% |
| 용량 | 들이마시는 시간 합계 **38초** |

## 쓰는 법

- **좌클릭을 누르고 있으면** 들이마십니다.
- 누르고 **0.75초** 뒤부터 가스가 나옵니다.
- 떼면 멈춥니다. 남은 양은 다음에 이어서 씁니다.
- 다 쓰면 빈 캔이 됩니다. 다시 누르면 빈 소리만 납니다.

## 효과

들이마시는 동안

- **스태미나 +1/20 초당** (`1 / (sprintTime + 9)`, sprintTime 11)
    - 걷기·서 있기 회복에 더해집니다.
- **취함**(`drunkness`)이 오릅니다.

취해 있는 동안

| 효과 | 내용 |
|---|---|
| 이동속도 | ×(drunknessSpeedEffect / 5 + 1) |
| 스태미나 | 소모·회복에 곡선 배율 |
| 조작 | 방향 전환이 미끄러지듯 느려짐, 화면 왜곡 |

- 멈추면 취함이 서서히 풀립니다.
- 곡선(`drunknessSpeedEffect` 등)은 씬 값입니다.
