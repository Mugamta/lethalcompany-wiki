# 섬광탄 (Stun grenade)

**Stun grenade** · 30 크레딧

던져서 터뜨리면 주변 몬스터를 기절시키고, 보는 사람의 눈을 멀게 합니다.
수제 섬광탄·부활절 달걀(폐기물)도 같은 스크립트(`StunGrenadeItem`)입니다. ([폐기물](../scrap/index.md))

## 기본 정보

| 항목 | 값 |
|---|---|
| 무게 | 5 lb |
| 배터리 | 없음 |
| 전도성 | 없음 |
| 최대 할인 | 80% |
| 재사용 | **안 됨** (터진 뒤에도 남지만 다시 못 씀) |

## 쓰는 법

1. **좌클릭**: 핀을 뽑습니다. 1초 걸립니다.
2. 핀을 뽑은 순간부터 **2.25초** 뒤 터집니다. 던지든 안 던지든 터집니다.
3. 다시 **좌클릭**: 던집니다.

- 던지면 보는 방향 **12m** 안의 벽이나 물체 앞에 떨어집니다. 아무것도 없으면 10m 앞입니다.
- **손에 든 채 터지면** 든 사람은 체력 **−20**, 눈부심 최대입니다.

## 몬스터 기절

- 터진 곳 **12m** 안의 몬스터가 대상입니다.
- 다음 중 하나면 기절합니다.
    - 몬스터 쪽에서 터진 곳이 보임 (시야 120°)
    - 사이에 벽이 없고 **11m** 안
- 기절 시간: **7.5초** × 몬스터별 배율 ([기절](../creatures/combat.md#기절))
- 섬광탄이 안 통하는 몬스터도 있습니다. ([생명체](../creatures/index.md))

## 플레이어 눈부심

```
세기 = 7 / 거리   (최대 1)
```

| 조건 | 세기 |
|---|---|
| 사이에 벽 | ÷13 |
| 2m 안 | 1 (최대) |
| 그쪽을 안 보고 있음 (시야 60° 밖) | ÷3 |

- 세기만큼 화면이 하얘지고 귀가 울립니다.
- 플레이어 체력은 손에 들고 있던 사람만 깎입니다.
