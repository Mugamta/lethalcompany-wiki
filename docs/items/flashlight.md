# 손전등 · 프로 손전등 (Flashlight)

**Flashlight** · 15 크레딧 / **Pro-flashlight** · 28 크레딧

같은 스크립트(`FlashlightItem`)입니다. 밝기와 배터리만 다릅니다.

## 기본 정보

| 항목 | 손전등 | 프로 손전등 |
|---|---|---|
| 가격 | 15 | 28 |
| 무게 | 0 lb | 5 lb |
| 배터리 | 140초 | 300초 |
| 전도성 | 없음 | 없음 |
| 최대 할인 | 80% | 80% |

## 조작

- **좌클릭**: 켜기/끄기
- **켠 채로 주머니에 넣으면** 헬멧 조명으로 계속 비춥니다. 배터리도 계속 닳습니다.
- 켜진 채로 바닥에 내려놓으면 바닥에서 계속 비춥니다.

## 소리

| 소리 | 범위 | 크기 |
|---|--:|--:|
| 켜기/끄기 | 7m | 0.4 |
| 배터리 다 됨 | 13m | 0.65 |

- 둘 다 몬스터가 듣습니다. ([소리](../creatures/noise.md#아이템))

## 깜빡임과 꺼짐

- **유령 소녀**가 나타날 때 손전등이 깜빡입니다. ([유령 소녀](../creatures/ghost-girl.md))
    - 시설 안에서 들고 있는 손전등은 **약 0.5초 동안 완전히 꺼집니다.**
        - 이 동안에는 스위치를 눌러도 켜지거나 꺼지지 않습니다. 딸깍 소리만 납니다.
    - 그 밖의 손전등은 같은 시간 동안 밝기가 무작위로 흔들립니다.
- 배전함이나 장치(Apparatus) 때문에 시설 전등이 깜빡일 때는 손전등에 영향이 없습니다.
