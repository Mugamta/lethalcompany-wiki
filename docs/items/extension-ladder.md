# 연장 사다리 (Extension ladder)

**Extension ladder** · 60 크레딧

바닥에 세우면 위로 펴지는 사다리입니다. 20초 뒤 저절로 접힙니다.

## 기본 정보

| 항목 | 값 |
|---|---|
| 무게 | 0 lb |
| 배터리 | 없음 |
| 전도성 | **있음** |
| 최대 할인 | **60%** |
| 최대 길이 | **9.72m** |

## 펴지는 순서

1. **좌클릭**하면 손에서 내려놓습니다.
2. 바닥에 닿고 **1초** 뒤 위로 펴집니다.
    - 위에 천장이 있으면 천장까지만 펴집니다.
3. **0.4초** 뒤 앞으로 기울어, 벽에 닿는 각도에서 멈춥니다.
4. 기운 각도에 따라 쓰임이 다릅니다.

| 기운 각도 (세운 상태 기준) | 결과 |
|---|---|
| 45° 미만 | 오를 수 있는 사다리 |
| 45° 이상 | 다리처럼 위를 걸어 건넘 |

- 기울기는 4.5° 단위로 확인합니다. 닿는 벽이 없으면 끝까지(약 90°) 눕습니다.

## 유지 시간

- 펴지기 시작하고 **15초** 뒤 깜빡이며 경고음을 냅니다.
- **20초** 뒤 접힙니다. 오르던 사람은 내려옵니다.
- 집으면 바로 접힙니다.

## 주의

- 길게(60% 넘게) 펴진 사다리가 반 넘게 기우는 동안 **아래에 있는 사람이 깔려 죽을 수 있습니다**(`killTrigger`).
- 비축 벌레 등 **몬스터가 내려놓아도 펴집니다.**
