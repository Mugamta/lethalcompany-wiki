# 자물쇠 따개 (Lockpicker)

**Lockpicker** · 20 크레딧

잠긴 문에 붙여 두면 저절로 문을 엽니다. 열쇠가 없어도 됩니다.

## 기본 정보

| 항목 | 값 |
|---|---|
| 무게 | 11 lb |
| 배터리 | 없음 |
| 전도성 | 없음 |
| 최대 할인 | 80% |

## 쓰는 법

1. 잠긴 문을 보고 **3m 안에서 좌클릭**합니다.
2. 자물쇠 따개가 손을 떠나 문에 붙습니다. 문 양쪽 중 **가까운 쪽**에 붙습니다.
3. **30초** 뒤 문이 열리고, 따개는 바닥에 떨어집니다.

- 30초는 문 프리팹 값(`DoorLock.maxTimeLeft`)입니다. 코드 기본값은 60입니다.
- 문을 보면 남은 시간이 "Picking lock: n sec."로 나옵니다.
- 이미 따는 중인 문에는 하나 더 붙일 수 없습니다.

## 중간에 떼면

- 붙어 있는 따개를 집으면 따기가 멈춥니다.
- **남은 시간은 처음(30초)으로 돌아갑니다.** 다시 붙이면 처음부터입니다.
