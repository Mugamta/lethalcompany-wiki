# 잽건 (Zap gun)

**Zap gun** · 400 크레딧

몬스터를 전기로 붙잡아 계속 기절시킵니다. 쏘는 동안 끌려가는 방향을 버텨야 합니다.

## 기본 정보

| 항목 | 값 |
|---|---|
| 무게 | 11 lb |
| 배터리 | 22초 (쏘는 동안) |
| 전도성 | **있음** |
| 최대 할인 | 80% |

## 쓰는 법

1. **좌클릭**: 앞쪽을 훑어 대상을 찾습니다. 0.125초마다 12번(**1.5초**) 찾습니다.
2. 찾으면 0.55초 뒤 전기가 이어집니다.
3. 쏘는 동안 화면 화살표 방향으로 **마우스를 당겨** 버팁니다.
4. 다시 **좌클릭**하면 멈춥니다.

**대상이 되는 조건**

| 조건 | 값 |
|---|---|
| 거리 | 0.7 ~ **13m** |
| 각도 | 시작할 때 정면 60°, 쏘는 중엔 80° 안 |
| 벽 | 사이에 없어야 함 |

- 0.15초마다 조건을 다시 확인합니다. 벗어나면 실패입니다.

## 과열

- 끌려가는 반대쪽으로 버티지 못하면 과열이 쌓입니다. 대상이 등 뒤(90° 밖)로 가도 쌓입니다.
- 과열이 **2**를 넘으면 실패합니다.
- 오래 쏠수록 끌어당김이 세지고 흔들림이 빨라집니다. 대상마다 난이도 배율이 다릅니다.

| 끝남 | 다시 쓸 수 있을 때까지 |
|---|--:|
| 직접 멈춤 | 0.25초 |
| 실패 (과열·조건 벗어남) | **5초** |

## 대상별 효과

| 대상 | 효과 | 난이도 배율 |
|---|---|--:|
| 몬스터 | 쏘는 동안 계속 기절 ([기절](../creatures/combat.md#기절)) | 몬스터별 |
| 플레이어 | 쏘는 동안 이동 방해 (속도 크게 감소) | 1.5 |
| 배전함 | 스위치가 전부 내려가 **시설 전기가 꺼짐** | 0.3 |

- 몬스터는 기절할 수 있고(`canBeStunned`), 기절 직후 무적 시간이 아니어야 합니다.
- 잽건은 피해를 주지 않습니다. 기절만 시킵니다.
