# 레이더 부스터 (Radar-booster)

**Radar-booster** · 60 크레딧

켜 두면 함선 모니터의 대상이 됩니다. 터미널로 소리를 내거나 섬광을 터뜨릴 수 있습니다.

## 기본 정보

| 항목 | 값 |
|---|---|
| 무게 | 19 lb |
| 배터리 | 없음 |
| 전도성 | **있음** |
| 최대 할인 | 80% |

## 조작

- **좌클릭**: 켜기/끄기
- **주머니에 넣으면 꺼집니다.** 바닥에 둔 채로 켜 두는 아이템입니다.
- 켜면 [모니터](../ship/index.md#모니터-레이더) 대상 목록에 들어갑니다.
    - 이름은 무작위로 붙고(시드 + 아이템 ID), 저장되어 다음 날에도 같습니다.
    - 스캔하면 이 이름이 보입니다.

## 터미널 명령

켜져 있을 때만 됩니다.

| 명령 | 효과 |
|---|---|
| `ping [이름]` | 소리. 범위 **12m**, 크기 **0.8** |
| `flash [이름]` | 섬광. 쿨타임 **2.25초** |

**ping**

- 몬스터가 듣습니다. 누를 때마다 "같은 자리 반복" 횟수가 2씩 오릅니다.
    - 5초마다 1씩 줄어듭니다.
    - 5m 넘게 옮겨 내려놓으면 0으로 돌아갑니다.

**flash**

- 섬광탄과 같은 방식으로 터집니다. ([섬광탄](stun-grenade.md#몬스터-기절))
- 몬스터 기절 시간: **1.75초** × 몬스터별 배율 (섬광탄은 7.5초)
- 플레이어 눈부심은 섬광탄보다 약합니다.
    - 세기 = 3.5 / 거리 × 0.8. 0.6을 넘으면 +0.3
    - 귀는 울리지 않습니다.
