- "대충 이렇다더라"가 아니라 **코드에 적힌 숫자와 조건**을 모읍니다.

## 이 위키의 원칙

!!! info "표기 규칙"
    - **IL 확인** = 게임 DLL의 메서드 본문(IL)을 직접 읽어서 확인한 내용입니다.
    - **에셋 값 / 프리팹 값 / 씬 값** = 코드가 아니라 유니티 에셋에 저장된 값입니다.
      게임 파일(`sharedassets*.assets`, `level*`)을 직접 읽었습니다.
    - **호스트만** = 방장 컴퓨터에서만 계산하고 다른 플레이어에게 보내지 않는 값입니다.
    - 시각은 게임 안 시계 기준, 거리는 미터(m)입니다.

- **확인 시점**: 2026년 11월 최신 버전(Unity 2022.3.62f2). 업데이트로 바뀔 수 있습니다.
- **바닐라 기준**: 모드 몬스터·아이템은 다루지 않습니다.
- **이름**: 한국어 패치 이름을 따르고, 영어 이름은 표에 괄호로 붙입니다.

## 자주 쓰는 용어

시드 (`randomMapSeed`)
:   레벨마다 정해지는 정수입니다. 모든 클라이언트가 같은 값을 받습니다.

    게임은 `System.Random(시드 + 고정값)`으로 용도별 난수를 만듭니다.
    그래서 **같은 시드면 같은 결과**가 나오는 것이 많습니다. (폐기물 배치, 증기 밸브 시각, 실내 안개, 늪 위치 등)

호스트 / 클라이언트
:   방장 컴퓨터가 서버입니다.
    몬스터 스폰, 대부분의 몬스터 AI, 금속 벼락 같은 판정은 호스트에서만 하고 결과만 보냅니다.

`normalizedTimeOfDay`
:   하루를 0~1로 나타낸 시각입니다. 0 = 06:00, 1 = 24:00.
    0.63(약 17:20)부터 해 질 녘입니다.

`currentDayTime`
:   하루 시작부터 흐른 게임 초(하루 1080초). 벤트 스폰 시각이 이 단위입니다.

파워 (`PowerLevel`)
:   몬스터마다 정해진 무게. 위성마다 실내·외부·주간 최대 파워가 있고, 그 안에서만 스폰됩니다.
