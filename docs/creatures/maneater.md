# 식인 괴물

**Maneater** · 실내 몬스터

아기일 때는 울며 관찰하고, 자라면 성체가 되어 쫓아옵니다.

## 능력치

| 항목 | 값 |
|---|---|
| 체력 | 5 |
| 공격력 | 즉사 |
| 공격 간격 | — |
| 이동속도 (m/s) | 아기 2.5~6.25 · 성체 6 |
| 파워 · 최대 | 2 · 1 |
| 섬광탄·잽건 | 통함 |
| 상태 번호 | 2 이상 = 공격 |

표 읽는 법은 [생명체](index.md#표-읽는-법)에 있습니다.

## 감지·추격

- **아기**: 시야 120° / 30m로 관찰만 합니다.
- **성체**: 대상을 쫓습니다.
- **놓침**: 실내 15m(외부 35m) 넘게 멀어지고 벽에 가리면 놓칩니다.

## 등장 위성

숫자는 **희귀도**(뽑기 가중치)입니다. 표에 없는 위성에는 나오지 않습니다.

| 위성 | 희귀도 |
|---|--:|
| [보우](../moons/vow.md) | 53 |
| [어슈어런스](../moons/assurance.md) | 15 |
| [아터피스](../moons/artifice.md) | 14 |
| [마치](../moons/march.md) | 9 |
| [오펜스](../moons/offense.md) | 7 |
| [애더먼스](../moons/adamance.md) | 5 |
| [다인](../moons/dine.md) | 2 |
