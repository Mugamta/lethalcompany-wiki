# 호두까기 인형 (Nutcracker)

**Nutcracker** · 실내 몬스터

머리를 돌려 감시하고, 감시 중에 움직이면 산탄총을 쏩니다.

## 능력치

| 항목 | 값 |
|---|---|
| 체력 | 5 |
| 공격력 | 발차기 즉사 · 산탄총 100/40/20 |
| 공격 간격 | — |
| 이동속도 (m/s) | 5.5 · 조준 2.25 · 추격 7 |
| 파워 · 최대 | 1 · 10 |
| 섬광탄·잽건 | 통함 |
| 상태 번호 | 2 공격/추격 |

표 읽는 법은 [생명체](index.md#표-읽는-법)에 있습니다.

## 감지·추격

1. 가장 가까운 플레이어가 27m 안이면, 60% 확률로 머리를 돌려 감시합니다.
2. 감시 중 시야 70° / 60m 안에서 **움직이면** 쏘고 쫓아옵니다.
    - 움직임 = 이동, 10m 안에서 시점 돌리기, 감정표현
3. 추격 중에는 시야 70° / 25m로 다시 찾습니다.

## 산탄총

정면 30° 안, 벽이 없어야 맞습니다.

| 거리 | 피해 |
|---|--:|
| 15m 안 | 100 |
| 23m 안 | 40 |
| 30m 안 | 20 |

- 발차기는 피해가 아니라 즉사입니다.
- 죽이면 **산탄총**(가치 60)을 얻습니다. ([폐기물](../scrap/index.md#몬스터특수-폐기물))

## 침공 레벨

호두까기 인형 파워가 20인 레벨에서는 실내 스폰 마릿수가 +2 됩니다. ([스폰](../moons/spawning.md))
