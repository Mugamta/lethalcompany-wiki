# 올드 버드

**Old Bird** · 외부 몬스터

거대한 기계. 시야 안 대상을 쫓아 밟고, 화염과 미사일을 씁니다.

## 능력치

| 항목 | 값 |
|---|---|
| 체력 | 불가 |
| 공격력 | 밟기 70/30 · 화염 · 미사일 |
| 공격 간격 | — |
| 이동속도 (m/s) | 걸음 11 · 돌진 35 |
| 파워 · 최대 | 3 · 20 |
| 섬광탄·잽건 | 통함 |

표 읽는 법은 [생명체](index.md#표-읽는-법)에 있습니다.

## 감지·추격

- **감지 범위**: 정면 58m 앞을 중심으로 한 반경 60m 구. 정면으로는 최대 약 118m까지.
- 시야각 안이고 벽이 없어야 합니다.
- 눈에 잘 안 띄는 대상(가시성 0.58 미만)은 30m 안에서만 봅니다.
- 날고 있을 때는 시야 35° / 120m.
- 안개 날씨에는 시야 거리가 최대 30m로 잘립니다.

## 잠든 올드 버드

1. 레벨을 만들 때 호스트가 하루 외부 스폰을 미리 돌려 봅니다.
2. 올드 버드가 뽑힐 때마다 **둥지**를 하나씩 놓습니다.
3. 실제 올드 버드가 스폰되면 첫 둥지 자리로 옮겨집니다. → **앞 둥지부터 깨어납니다.**
4. 장치(코어)를 뽑으면 둥지마다 올드 버드가 바로 스폰됩니다.

자세한 내용은 [스폰](../moons/spawning.md#잠든-올드-버드)에 있습니다.
