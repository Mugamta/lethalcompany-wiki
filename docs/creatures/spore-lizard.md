# 포자 도마뱀

**Spore Lizard** · 실내 몬스터

보이면 도망칩니다. 몰리거나 맞으면 반격합니다.

## 능력치

| 항목 | 값 |
|---|---|
| 체력 | 불가 |
| 공격력 | 20 |
| 공격 간격 | 1초 |
| 이동속도 (m/s) | 4 · 도망 최대 12 |
| 파워 · 최대 | 1 · 2 |
| 섬광탄·잽건 | 통함 |
| 상태 번호 | 2 공격/추격 |

표 읽는 법은 [생명체](index.md#표-읽는-법)에 있습니다.

## 감지·추격

- 시야 45° / 20m (2m 무관)에 보이면 **도망칩니다.** 쫓아오지 않습니다.
- 도망 중 7m 안에 1초 있으면 발을 구르고, 5m 안으로 오면 꼬리를 흔들어 포자를 뿜습니다. 그 뒤에도 5m 안이면 공격합니다.
- 도망칠 곳이 없으면 멈춰서 1초 뒤 발 구르기, 3초 뒤 포자, 그다음 공격합니다.
