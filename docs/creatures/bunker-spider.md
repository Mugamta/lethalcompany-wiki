# 벙커 거미 (Bunker Spider)

**Bunker Spider** · 실내 몬스터

거미줄을 치고 기다리다, 보이거나 거미줄을 밟으면 쫓아옵니다.

## 능력치

| 항목 | 값 |
|---|---|
| 체력 | 5 |
| 공격력 | 90 |
| 공격 간격 | 1초 |
| 이동속도 (m/s) | 4.25~5.04 |
| 파워 · 최대 | 2 · 1 |
| 섬광탄·잽건 | 통함 |
| 상태 번호 | 2 공격/추격 |

표 읽는 법은 [생명체](index.md#표-읽는-법)에 있습니다.

## 감지·추격

- **감지**: 시야 80° / 15m (2m 무관)
- **추격 시간**: 12.5초
- **거미줄을 밟으면** 다음 중 하나일 때 추격합니다.
    - 둥지에서 25m 안
    - 거미에서 15m 안

## 거미줄

- 거미줄에 걸리면 이동이 방해됩니다(`isMovementHindered`). 속도 ÷(2 × 배율).
- 방해받으며 걸으면 스태미나가 빨리 줄어듭니다. ([플레이어](../player/index.md))
