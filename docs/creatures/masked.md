# 가면 쓴 사람

**Masked** · 실내 몬스터

플레이어를 흉내 내며 돌아다니다, 붙잡으면 즉사시킵니다.

## 능력치

| 항목 | 값 |
|---|---|
| 체력 | 4 |
| 공격력 | 즉사 |
| 공격 간격 | — |
| 이동속도 (m/s) | 걷기 3.8 · 달리기 7~8 |
| 파워 · 최대 | 1 · 10 |
| 섬광탄·잽건 | 통함 |
| 상태 번호 | 1 추격 |

표 읽는 법은 [생명체](index.md#표-읽는-법)에 있습니다.

## 감지·추격

- **감지** (둘 중 하나)
    - 시야 45° / 60m
    - 플레이어가 20m 안에서 정면(4° 이내)으로 쳐다봄
- **추격 중**: 시야 70° / 50m (3m 무관)
- **끝**: 10초 동안 놓치면 포기합니다.

## 가면 폐기물

- 희극·비극 가면을 **손에 들고 사용 버튼을 누르고 있으면** 얼굴에 대고 있게 됩니다.
    - 손에 든 지 10초가 지나면, 대고 있는 동안 5초마다 65% 확률로 달라붙기 시작합니다.
    - 달라붙기 시작하면 버튼을 떼거나 버려도 멈출 수 없습니다. 5초 뒤(한 번 취소된 적이 있으면 8초 뒤) 질식사하고 가면 쓴 사람이 됩니다.
- 뒤집어쓰는 순간 소리(8m / 크기 0.6)가 납니다. 눈 없는 개가 8m 안 어디서든 바로 분노합니다.

## 등장 위성

숫자는 **희귀도**(뽑기 가중치)입니다. 표에 없는 위성에는 나오지 않습니다.

| 위성 | 희귀도 |
|---|--:|
| [아터피스](../moons/artifice.md) | 89 |
| [타이탄](../moons/titan.md) | 32 |
| [렌드](../moons/rend.md) | 25 |
| [애더먼스](../moons/adamance.md) | 2 |

## 시간대

그 시각의 희귀도에 곱하는 값입니다. (1 = 그대로, 0 = 안 나옴) 자세한 설명은 [생명체](index.md#시간대)에 있습니다.
