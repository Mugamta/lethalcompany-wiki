# 올가미 벼룩 (Snare Flea)

**Snare Flea** · 실내 몬스터

천장에 붙어 있다가 바로 밑을 지나가면 떨어져 머리에 달라붙습니다.

## 능력치

| 항목 | 값 |
|---|---|
| 체력 | 3 |
| 공격력 | 10 (달라붙음) |
| 공격 간격 | 2초 |
| 이동속도 (m/s) | 0 → 5.2 (서서히) |
| 파워 · 최대 | 1 · 4 |
| 섬광탄·잽건 | 통함 |

표 읽는 법은 [생명체](index.md#표-읽는-법)에 있습니다.

## 감지·추격

- 천장에 붙어 있다가, 바로 밑(반경 2.15m, 아래로 20m)을 지나가면 떨어집니다.
- 달라붙으면 2초마다 피해 10을 줍니다.

## 등장 위성

숫자는 **희귀도**(뽑기 가중치)입니다. 표에 없는 위성에는 나오지 않습니다.
