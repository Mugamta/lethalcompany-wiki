# 몬스터 체력·공격·상태

## 플레이어 무기

### 몬스터를 때릴 때

| 무기 | 피해 | 범위 |
|---|---|---|
| 삽·정지 표지판·양보 표지판 | `shovelHitForce` | 반경 0.8, 거리 1.5 |
| 부엌칼 | `knifeHitForce` | 거리 0.75 |
| 산탄총 | 거리에 따라 2~5 | |

- **삽 속도**: 들기 0.35초 + 휘두름 0.13초 + 회복 0.3초
- **부엌칼**: 마지막 피해 후 0.43초 동안은 피해가 안 들어갑니다.
- **산탄총 피해**

| 거리 | 피해 |
|---|--:|
| 3.7m 안 | 5 |
| 6m 안 | 3 |
| 그 밖 | 2 |

### 산탄총에 플레이어가 맞을 때

정면 30° 안, 벽이 없어야 맞습니다.

| 거리 | 피해 |
|---|--:|
| 15m 안 | 100 |
| 23m 안 | 40 |
| 30m 안 | 20 |

- 호두까기 인형 발차기는 피해가 아니라 즉사입니다.
- 헛스윙 소리와 산탄총 발사음은 몬스터가 못 듣습니다. ([소리](noise.md))

## 몬스터 체력

- 현재 체력은 `EnemyAI.enemyHP`입니다. **최대 체력 값은 따로 없습니다.**
- 터렛은 몬스터에게 피해를 주지 않습니다.
- 늪지 점액괴어는 체력이 **0 미만**일 때만 죽습니다. 0이면 살아 있습니다.

### 처치 불가

다음 중 하나면 죽일 수 없습니다.

- `enemyType.canDie`가 꺼져 있음
- 맞는 처리(`HitEnemy`)를 따로 만들지 않음 → 기본 처리는 소리만 냅니다.

처치 불가 몬스터: 배회 메뚜기, 포자 도마뱀, 코일헤드, 광대, 올드 버드, 이발사, 회로 벌, 위장 말벌, 유령 소녀 등

## 몬스터 공격력

- **피해**: `DamagePlayer`에 넘기는 값
- **간격**: 다시 공격하기까지 기다리는 시간 (`OnCollideWithPlayer`)
- **즉사형**은 피해 대신 `KillPlayer`를 부릅니다.
- **공격 안 함**: 튤립 뱀, 배회 메뚜기, 만티코일

몬스터별 값은 [생명체](index.md#능력치) 표에 있습니다.

!!! note "페이오파의 공격 간격"
    코드에 간격 값이 없습니다.
    할퀴기 애니메이션이 날 때마다, 3초 안에 닿으면 피해 7 + 밀쳐냄입니다.
    실제 간격은 애니메이션 길이가 정합니다.

## 기절

```
남은 기절 시간(초) = 타이머 × stunTimeMultiplier
```

- 기절하면 타이머가 정해지고(`SetEnemyStunned`), 매 프레임 줄어듭니다.
- 이미 기절 중이면 새 값으로 덮어씁니다.
- 기절이 끝난 직후 0.5초는 다시 기절하지 않습니다.
- 잽건 등으로 계속 기절시키는 동안(`stunnedIndefinitely > 0`)은 안 풀립니다.
- 기절은 각 클라이언트가 따로 계산합니다. 동기화되지 않습니다.

## 몬스터별 상태 번호

몬스터 상태는 `currentBehaviourStateIndex`로 알 수 있습니다. 모든 클라이언트에 동기화됩니다.

| 몬스터 | 상태 |
|---|---|
| 브래컨 (Bracken) | 0 몰래 접근 · 1 피함/시체 운반 · 2 분노 |
| 비축 벌레 (Hoarding Bug) | 0 폐품 찾기 · 1 운반/둥지 지킴 · 2 분노 |
| 늪지 점액괴어 (Backwater Gunkfish) | 0 숨을 곳으로 이동 · 1 위장 |
| 납치범 여우 (Kidnapper Fox) | 0 숨음 · 1 노려봄 · 2 혀 공격 |
| 숲지기, 코일헤드, 썸퍼, 가면 쓴 사람 | 1 추격 |
| 광대, 호두까기, 개코 매, 거미, 포자 도마뱀, 거대 딱따구리 | 2 공격/추격 |
| 집사, 회로 벌 | 1 이상 = 공격 |
| 눈 없는 개 (Eyeless Dog), 맨이터 (Maneater) | 2 이상 = 공격 |
| 페이오파 (Feiopar) | 2 공격 (나무 위가 아니면 0도 공격) |

**같이 보면 좋은 값**

- 브래컨: `isInAngerMode`(분노), `carryingPlayerBody`(시체 운반)
- 비축 벌레: `heldItem`, `watchingPlayer`, `angryAtPlayer`
- 숲지기: `chasingPlayer`
- 늪지 점액괴어: 위장 중 1.5m 안으로 다가가거나 때리면 튀어나와 돌진
- 납치범 여우: 0으로 돌아가도 대상(`targetPlayer`)을 안 비움

### 유령 소녀 (Ghost Girl)

홀린 한 명의 화면에서만 의미 있는 값입니다.

- 본 횟수(`timesSeenByPlayer`): 볼 때마다 +1
- 추격 시간(`chaseTimer`): 20초

| 조건 | 추격 |
|---|---|
| 본 횟수 2회 초과 | 85% |
| 본 횟수 3~4회 초과 | 추격 |
| 2회 이상 본 뒤 5m 안으로 다가옴 | 65% |

- 50m 멀어지면 추격이 끝납니다.
- 소녀가 나올 때 스폰 난수가 초기화됩니다. ([스폰](../moons/spawning.md#유령-소녀가-난수를-초기화함))

## 비축 벌레 둥지

- 둥지 위치(`HoarderBugAI.nestPosition`)는 모든 클라이언트에 동기화됩니다.
- 아직 안 정해졌으면 (0, 0, 0)입니다.
