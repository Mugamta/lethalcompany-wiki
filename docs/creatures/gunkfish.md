# 늪지 점액괴어 (Backwater Gunkfish)

**Backwater Gunkfish** · 실내 몬스터

늪이나 물속에 위장해 있다가, 가까이 오거나 맞으면 튀어나와 돌진합니다.

## 능력치

| 항목 | 값 |
|---|---|
| 체력 | 4* |
| 공격력 | — |
| 공격 간격 | — |
| 이동속도 (m/s) | 0 → 5.5 · 위장 해제 돌진 |
| 파워 · 최대 | 0.5 · 6 |
| 섬광탄·잽건 | 통함 |
| 상태 번호 | 0 숨을 곳으로 이동 · 1 위장 |

표 읽는 법은 [생명체](index.md#표-읽는-법)에 있습니다.

## 감지·추격

- 시야 110° / 25m (7m 무관)
- 위장 중 1.5m 안으로 다가가거나 때리면 튀어나와 돌진합니다.

## 체력 판정

- 체력이 **0 미만**이 되어야 죽습니다. 0이면 살아 있습니다.
- 체력 4이므로 삽(1)으로는 다섯 번 때려야 합니다.

## 등장 위성
