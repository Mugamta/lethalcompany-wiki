# 하이그로디어

**Hygrodere** · 실내 몬스터

시야 감지 없이 가장 가까운 사람 쪽으로 천천히 움직입니다. 붐박스를 들으면 얌전해집니다.

## 능력치

| 항목 | 값 |
|---|---|
| 체력 | 3 |
| 공격력 | 35 |
| 공격 간격 | 0.25초 |
| 이동속도 (m/s) | 0.5 → 최대 3 |
| 파워 · 최대 | 1 · 2 |
| 섬광탄·잽건 | 통함 |

표 읽는 법은 [생명체](index.md#표-읽는-법)에 있습니다.

## 감지·추격

- 시야 감지가 없습니다. 소리는 **붐박스**만 듣습니다.
    - 벽 없이 12m 안에서 붐박스가 울리면 2초 동안 얌전해집니다. 공격하지 않고 몸이 1.5m로 줄어듭니다.
- 거리 제한 없이 가장 가까운 플레이어 쪽으로 천천히 움직입니다.
- **몸이 닿는 범위**: 중심에서 최대 **3.5m**(프리팹 값 `slimeRange`, 코드 기본값 8)
    - 경사를 오를 때는 절반(최소 1.5m)
    - 맞으면 18초 동안 화가 나서 9.5m(3.5 + 6)까지 늘어납니다.
    - 기절하면 2m로 줄어듭니다.
