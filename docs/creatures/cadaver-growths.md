# 시체 증식종

**Cadaver Growths** · 실내 몬스터

방을 따라 퍼지며 근처 플레이어를 감염시키는 식물입니다. 움직이지 않습니다.

## 능력치

| 항목 | 값 |
|---|---|
| 체력 | 불가 |
| 공격력 | 감염 |
| 공격 간격 | — |
| 이동속도 (m/s) | 0 (고정) |
| 파워 · 최대 | 2 · 1 |
| 섬광탄·잽건 | **안 통함** |

표 읽는 법은 [생명체](index.md#표-읽는-법)에 있습니다.

## 감지·추격

- 감염된 방(타일)에서 문으로 이어진 옆 방으로 퍼집니다.
- 근처 플레이어를 감염시킵니다. 감염 진행·치료 수치는 [시체 증식](cadaver.md)에 있습니다.

## 감염이 끝나면

- 감염 **35% 초과**에서 죽으면 시체에서 시체 증식종이 생깁니다(`bloomOnDeath`).
- 감염 **100%**가 되면 발아가 시작되고, 끝까지 가면 터져 죽습니다.
- 터지면 [시체 증식종(개화)](cadaver-bloom.md)가 생깁니다.
- 감염 중에는 이동속도 ×0.75입니다. ([플레이어](../player/index.md#포자-감염-시체-증식))

## 등장 위성

숫자는 **희귀도**(뽑기 가중치)입니다. 표에 없는 위성에는 나오지 않습니다.

| 위성 | 희귀도 |
|---|--:|
| [애더먼스](../moons/adamance.md) | 200 |
| [아터피스](../moons/artifice.md) | 34 |
| [다인](../moons/dine.md) | 12 |
| [렌드](../moons/rend.md) | 6 |

## 시간대
