# 비축 벌레 (Hoarding Bug)

**Hoarding Bug** · 실내 몬스터

폐품을 둥지로 모읍니다. 둥지 물건을 건드리거나 가까이 있으면 분노합니다.

## 능력치

| 항목 | 값 |
|---|---|
| 체력 | 3 |
| 공격력 | 30 (화났을 때) |
| 공격 간격 | 0.5초 |
| 이동속도 (m/s) | 6 · 분노 18 |
| 파워 · 최대 | 1 · 10 |
| 섬광탄·잽건 | 통함 |
| 상태 번호 | 0 폐품 찾기 · 1 운반/둥지 지킴 · 2 분노 |

표 읽는 법은 [생명체](index.md#표-읽는-법)에 있습니다.

## 감지·추격

- **평소**: 시야 70° / 30m (1.2m 무관)로 지켜보기만 합니다.
- **분노 조건** (하나라도)
    - 둥지에 있던 물건을 들고 있음
    - 둥지 4m 안에 있음 (추격 중이면 8m)
    - 2.5m 안에서 보이는 동안 0.2초마다 짜증 +0.2 → 2.5를 넘으면(누적 약 2.6초) 분노. **짜증은 줄지 않고 하루 내내 쌓입니다.**
- **분노 시간**: 3.25초 (계속 갱신됨)

## 둥지

- 둥지 위치(`HoarderBugAI.nestPosition`)는 모든 클라이언트에 동기화됩니다.
- 아직 안 정해졌으면 (0, 0, 0)입니다.
- 같이 보면 좋은 값: `heldItem`, `watchingPlayer`, `angryAtPlayer`

## 침공 레벨

비축 벌레 파워가 30인 레벨에서는 실내 스폰 마릿수가 +2 됩니다. ([스폰](../moons/spawning.md))
