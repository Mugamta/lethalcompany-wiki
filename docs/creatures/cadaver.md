# 시체 증식

시체 증식 식물(`CadaverGrowthAI`)은 방(타일)을 따라 퍼지며 플레이어를 감염시킵니다. 다 자라면 `CadaverBloomAI`가 됩니다.

## 퍼짐

- `GrowthTiles`: 감염된 방 목록(`tile`, `plantsInTile`, `eradicated`). RPC로 동기화됩니다.
- 다음에 퍼질 후보 = 감염된 방의 문(`UsedDoorways[].ConnectedDoorway.Tile`)으로 이어진 미감염 방.

## 감염 진행

- `playerInfections[플레이어 번호]`: `infected`, `severe`, `infectionMeter`(0~1), `burstMeter`.
- 각자 **자기 감염만** 계산하고 `SyncInfectionMeterRpc`로 팀원에게 알립니다. `burstMeter`는 본인만 압니다.

진행 배율:

| 조건 | 배율 |
|---|---|
| 야외 햇빛 | ×1.15 |
| 15m 안에 팀원 | ×0.7 (92.5% 넘으면 ×1.5) |
| 체력 ≤ 40 | ×1.15 |
| 체력 100 | ×0.85 |
| 혼자 플레이 | ×0.45 |

- 100%가 되면 발아: 초당 Lerp(3, 0.015, 가장 가까운 팀원 거리/30) × 0.22(프리팹 값 `BurstSpeedMultiplier`, 코드 기본값 0.25). 0.9 이상이면 이동이 느려지고 1이 되면 **터집니다.**

## 치료

| 방법 | 효과 |
|---|---|
| 켜진 **배 샤워**에 들어감 | 8% 미만이면 초당 −8%로 완치. 8% 이상이면 ×0.85만 |
| **다른 사람이** 제초제 분사 (5m, 정면 40°) | 0.33초마다 −10%, 체력 −8. 단 100% 도달 후(발아 중) 맞으면 **즉시 터짐** |
