# 페이오파 (Feiopar)

**Feiopar** · 외부 몬스터

나무 위에서 노리다 덮칩니다.

## 능력치

| 항목 | 값 |
|---|---|
| 체력 | 4 |
| 공격력 | 7 + 밀쳐냄 |
| 공격 간격 | 할퀴기 애니메이션마다 |
| 이동속도 (m/s) | 14~24 · 공격 23 |
| 파워 · 최대 | 2 · 6 |
| 섬광탄·잽건 | 통함 |
| 상태 번호 | 2 공격 (나무 위가 아니면 0도 공격) |

표 읽는 법은 [생명체](index.md#표-읽는-법)에 있습니다.

## 감지·추격

- 나무 위에서 대상을 노리다 덮칩니다.
- 안개 날씨에도 시야가 잘리지 않는 유일한 외부 몬스터입니다.

## 공격 간격

코드에 간격 값이 없습니다.
할퀴기 애니메이션이 날 때마다, 3초 안에 닿으면 피해 7 + 밀쳐냄입니다.
실제 간격은 애니메이션 길이가 정합니다.

## 등장 위성

숫자는 **희귀도**(뽑기 가중치)입니다. 표에 없는 위성에는 나오지 않습니다.

| 위성 | 희귀도 |
|---|--:|
| [보우](../moons/vow.md) | 100 |
| [마치](../moons/march.md) | 28 |

## 시간대

그 시각의 희귀도에 곱하는 값입니다. (1 = 그대로, 0 = 안 나옴) 자세한 설명은 [생명체](index.md#시간대)에 있습니다.
