# 숲지기

**Forest Keeper** · 외부 몬스터

보이는 동안 게이지가 차고, 다 차면 쫓아와 잡아먹습니다.

## 능력치

| 항목 | 값 |
|---|---|
| 체력 | 38 |
| 공격력 | 즉사 |
| 공격 간격 | — |
| 이동속도 (m/s) | 5 · 추격 최대 7~8 |
| 파워 · 최대 | 3 · 3 |
| 섬광탄·잽건 | 통함 |
| 상태 번호 | 1 추격 |

표 읽는 법은 [생명체](index.md#표-읽는-법)에 있습니다.

## 감지·추격

- **시야**: 50° / 70m (3m 무관). 안개 날씨에는 최대 30m.
- 보이는 동안 **게이지**가 차고, 1이 되면 추격합니다.
- **초당 증가** = 주시도 × 계수 / (0.21 × 거리)
    - 계수 = 1 + (서 있지 않으면 +1) + (움직이면 +1)
    - 가까울수록, 서서 움직일수록 빨리 찹니다.
- 안 보이면 초당 0.33씩 줄어듭니다.

## 알아 둘 것

- 추격이 끝나도 `targetPlayer`를 비우지 않습니다. 실제 추격 여부는 상태 번호나 `chasingPlayer`를 보세요.
- 무너지는 다리에 올라서면 초당 내구도를 1/4.25씩 깎습니다. ([시설 구조물](../environment/facility.md#무너지는-다리))
- 소리 이벤트를 내지 않습니다.
