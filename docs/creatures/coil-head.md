# 코일헤드

**Coil-Head** · 실내 몬스터

보고 있으면 멈추고, 안 보면 빠르게 다가옵니다.

## 능력치

| 항목 | 값 |
|---|---|
| 체력 | 불가 |
| 공격력 | 90 |
| 공격 간격 | 0.2초 |
| 이동속도 (m/s) | 14.5 (안 볼 때) |
| 파워 · 최대 | 1 · 5 |
| 섬광탄·잽건 | 통함 |
| 상태 번호 | 1 추격 |

표 읽는 법은 [생명체](index.md#표-읽는-법)에 있습니다.

## 감지·추격

- **추격 시작** (둘 중 하나)
    - 방향 상관없이 벽 없이 30m 안에 있고, 다가가는 길이 플레이어 시야에 안 걸림
    - 플레이어가 코일헤드를 봄 (68° / 60m)
- **끝**: 40m 넘게 멀어지고, 시야(180° / 140m)가 4.5초 끊기면 포기합니다.
