# 브래컨

**Bracken** · 실내 몬스터

가장 가까운 사람에게 몰래 다가가 목을 꺾습니다. 들키면 물러나고, 계속 쳐다보면 분노합니다.

## 능력치

| 항목 | 값 |
|---|---|
| 체력 | 5 |
| 공격력 | 즉사 |
| 공격 간격 | — |
| 이동속도 (m/s) | 몰래 4~9 · 분노 3→12 |
| 파워 · 최대 | 3 · 1 |
| 섬광탄·잽건 | 통함 |
| 상태 번호 | 0 몰래 접근 · 1 피함/시체 운반 · 2 분노 |

표 읽는 법은 [생명체](index.md#표-읽는-법)에 있습니다.

## 감지·추격

- **평소**: 거리 제한 없이 가장 가까운 플레이어에게 몰래 다가갑니다.
- **들키면**: 플레이어가 브래컨을 보면(30° / 60m) 물러납니다.
- **분노**: 물러나는 중에도 가까이서 계속 쳐다보면 화가 나서 추격합니다.

## 내는 소리

눈 없는 개가 들으면 이 몬스터 쪽으로 갑니다.

| 소리 | 범위 | 크기 | 개가 바로 분노 |
|---|--:|--:|--:|
| 소리 | 7m | 0.8 | 7m 전부 |

## 같이 보면 좋은 값

- `isInAngerMode`: 분노 중
- `carryingPlayerBody`: 시체를 옮기는 중
