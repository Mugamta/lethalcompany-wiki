# 광대 (Jester)

**Jester** · 실내 몬스터

따라다니다 태엽을 감고, 튀어나오면 시설 안 아무나 쫓습니다.

## 능력치

| 항목 | 값 |
|---|---|
| 체력 | 불가 |
| 공격력 | 즉사 |
| 공격 간격 | — |
| 이동속도 (m/s) | 5 · 튀어나온 뒤 0→18 |
| 파워 · 최대 | 3 · 1 |
| 섬광탄·잽건 | 통함 |
| 상태 번호 | 2 공격/추격 |

표 읽는 법은 [생명체](index.md#표-읽는-법)에 있습니다.

## 감지·추격

1. 시야 70° / 40m에 보이고 걸어갈 길이 있으면 따라다닙니다.
2. 13~21초 뒤 태엽을 감기 시작합니다. 혼자면 25~42초 뒤.
3. 35~40초 뒤 튀어나옵니다.
4. 튀어나온 뒤에는 거리 제한 없이 시설 안 아무나 쫓습니다.

## 등장 위성

숫자는 **희귀도**(뽑기 가중치)입니다. 표에 없는 위성에는 나오지 않습니다.

| 위성 | 희귀도 |
|---|--:|
| [아터피스](../moons/artifice.md) | 92 |
| [타이탄](../moons/titan.md) | 71 |
| [렌드](../moons/rend.md) | 60 |
| [다인](../moons/dine.md) | 6 |
| [마치](../moons/march.md) | 1 |
| [애더먼스](../moons/adamance.md) | 1 |
