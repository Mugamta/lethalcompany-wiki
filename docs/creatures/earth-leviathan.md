# 육지 레비아탄 (Earth Leviathan)

**Earth Leviathan** · 외부 몬스터

땅속에서 다가와 솟아오르며 삼킵니다.

## 능력치

| 항목 | 값 |
|---|---|
| 체력 | 불가 |
| 공격력 | 즉사 |
| 공격 간격 | — |
| 이동속도 (m/s) | 4 |
| 파워 · 최대 | 2 · 3 |
| 섬광탄·잽건 | **안 통함** |

표 읽는 법은 [생명체](index.md#표-읽는-법)에 있습니다.

## 감지·추격

- 15m 안에 있는 가장 가까운 플레이어를 노립니다. 다음 플레이어는 빼고 고릅니다.
    - 함선 안(`isInHangarShipRoom`)이나 함선 바닥 위(`isInElevator`)
    - 함선 주변 스폰 금지 지점(`SpawnDenialPoint`) 10m 안
- 대상이 4m 안에 오면 AI 주기(0.35초, 프리팹 값)마다 17% 확률로 솟아오릅니다. 함선 실내 9m 안에서는 솟아오르지 않습니다.
- 추격은 6초. 대상이 22m 넘게 멀어지거나 함선에 들어간 상태가 6초 이어지면 포기합니다.
