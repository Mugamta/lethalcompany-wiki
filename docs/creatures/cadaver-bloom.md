# 시체꽃 (Cadaver Bloom)

**Cadaver Bloom** · 특수 몬스터

시체 증식종 감염자가 터지면 생기는 몬스터입니다.

## 능력치

| 항목 | 값 |
|---|---|
| 체력 | 4 |
| 공격력 | 30 |
| 공격 간격 | 0.65초 |
| 이동속도 (m/s) | 5~10 · 돌진 7~18 |
| 파워 · 최대 | 3 · 8 |
| 섬광탄·잽건 | 통함 |

표 읽는 법은 [생명체](index.md#표-읽는-법)에 있습니다.

## 감지·추격

- 희귀도로 뽑히지 않습니다. 감염자가 터질 때만 생깁니다.

## 등장 위성

희귀도로 뽑히지 않는 특수 몬스터입니다.
