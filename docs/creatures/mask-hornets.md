# 위장 말벌

**Mask Hornets** · 특수 몬스터

집사가 죽으면 나와서 쫓아옵니다.

## 능력치

| 항목 | 값 |
|---|---|
| 체력 | 불가 |
| 공격력 | 10 |
| 공격 간격 | 0.5초 |
| 이동속도 (m/s) | 3부터 가속 |
| 파워 · 최대 | 2 · 1 |
| 섬광탄·잽건 | 통함 |

표 읽는 법은 [생명체](index.md#표-읽는-법)에 있습니다.

## 감지·추격

- 희귀도로 뽑히지 않습니다. [집사](butler.md)가 죽을 때만 나옵니다.
- 3부터 점점 빨라지며 쫓아옵니다.

## 등장 위성

희귀도로 뽑히지 않는 특수 몬스터입니다.
