# 리썰 컴퍼니 메커니즘 위키

Lethal Company 게임 코드를 직접 확인해 정리한 한국어 메커니즘 위키입니다.
[MkDocs Material](https://squidfunk.github.io/mkdocs-material/)로 만들고 GitHub Pages로 배포합니다.

## 미리 보기

```powershell
pip install -r requirements.txt
mkdocs serve
```

## 배포

1. GitHub에 `lethalcompany-wiki` 저장소를 만들고 푸시합니다.
2. 저장소 Settings → Pages → Source를 **GitHub Actions**로.
3. `main`에 푸시할 때마다 자동 배포됩니다.

다른 저장소 이름이나 계정을 쓰면 `mkdocs.yml`의 `site_url`, `repo_url`을 바꾸세요.

Lethal Company는 Zeekerss의 게임이며, 이 위키는 비공식 팬 문서입니다.
